## 1. 收集的信息及目的

### 1-1. 直接输入的信息

| 项目 | 目的 |
|------|------|
| 待办标题、备注、截止日期、标签、优先级 | 待办管理 |
| 个人画像类型、描述 | AI 优先级个性化 |

### 1-2. 自动生成、收集的信息

| 项目 | 收集方式 | 目的 |
|------|-----------|------|
| Audit 事件（创建、完成、删除时间及来源） | 处理待办时自动记录 | 行为模式分析 |
| 行为模式分析结果（完成时段、按标签统计） | 设备内计算、可选的 OpenAI 说明请求 | 供用户审核的行为说明及优先级参考 |
| 应用设置值（AI 提供商选择、邮箱与日历选项等） | 保存设置 | 功能运行 |

### 1-3. 邮件集成（Gmail、Outlook，可选，在用户明确同意后启用）

- **收集项目及权限**：收件箱邮件标题、发件人、摘要片段、正文。Gmail OAuth 连接请求 `gmail.modify` 权限，可将用户查看邮件、标记已读及移至垃圾箱的操作反映到 Gmail 服务器。Gmail、Outlook IMAP 连接使用相应账户的应用专用密码。
- **目的**：在设备端对完整邮件正文进行摘要和整理，根据待审核/处理项目建议待办，并在用户审核后保存。
- **存储位置**：邮件原文与分析的权威副本保存在设备内的独立存储库。明确同意完整 iCloud 存储范围后，会复制至同一 Apple 账户的 CloudKit 私有数据库。自动邮件分析在设备内处理，针对所选邮件的 OpenAI 请求适用下述第 1-5 节的单独同意。
- **身份验证信息**：OAuth 令牌和 IMAP 应用专用密码保存在 Keychain，用于相应提供商的身份验证。同意完整存储并确认账户后，可通过 iCloud 钥匙串恢复；运行机密的设备级访问控制、后台许可及槽位指针不会迁移至新设备。
- **邮件服务器通信**：连接 Google LLC 的 Gmail REST API（`gmail.googleapis.com`）或 TLS IMAP（`imap.gmail.com:993`），以及 Microsoft 的 Outlook TLS IMAP（`outlook.office365.com:993`），以查询邮件并反映用户执行的标记已读、移至垃圾箱操作。
- **定期设备内存储**：可独立于自动分析邮件设置，定期保存列表和完整正文。后台获取仅适用于用户在此设备上已授权的账户，实际执行时间由 iOS 决定。对于未完成或先前不完整的正文，在重新确认完整正文之前，不会用作待办建议的依据。
- **HTML 邮件的外部视觉资源**：打开 HTML 邮件时，可能会自动加载 HTTPS 图片、样式和字体。相应外部主机可能记录查看时间和设备 IP。JavaScript、表单、框架、媒体及 HTTP 资源会被阻止。

### 1-4. 日历集成（可选，在授予系统权限后启用）

- **收集项目**：日历事件（EventKit，读取和写入）。
- **目的**：仅在用户主动请求或另行同意自动添加时，将符合条件的待办添加至所选系统日历，并将日历日程导入为待办。自动添加默认关闭，健康（`health:`）来源不参与自动添加。目标账户通过设备的系统日历设置连接，不另行添加 OAuth。
- **处理位置**：设备内系统日历框架（EventKit）。单独发送给 OpenAI 的日历事件上下文会将标题遮盖为 `Busy`，只包含开始和结束时间。不过，从外部日历导入并确认为进行中的待办，属于一般待办共享同意范围，其标题和备注可能被发送。

### 1-5. 待办优先级及可选的外部分析

- 默认 AI 为 Apple Intelligence。仅在硬件不受支持的设备上，明确允许测试功能中的本地语言模型替代后，才使用用户主动安装的模型。不会将受支持设备上的停用或模型准备中状态视为同意使用其他模型。没有可用模型时，以设备内规则处理。除待办排序中明确选择外部提供商的情况外，会议、个人画像和行为的默认分析在设备内进行；个人画像和行为的 GPT 再次分析，须已连接账户，并另行启用及同意共享，才能主动请求。
- **App Store 国家/地区限制**：StoreKit 确认的中国大陆商店（`CHN`），或国家信息尚未确认的状态下，会阻止 ChatGPT/OpenAI 界面以及身份验证、模型查询、连接测试和分析请求。应用会观察商店变化，并在激活时重新检查；切换为阻止状态时，将停止进行中的请求及迟到结果的应用。国家信息仅在内存中用于判断可用性，不存为客户画像，也不用于广告或跟踪。更改语言不会解除此限制。
- **应用数据的 OpenAI 分析请求**：须同时满足提供商启用、官方 ChatGPT 连接、订阅使用权限，以及针对各类数据的单独同意。仅在相应同意范围内使用一般待办标题、备注、截止时间、可用时间、所选邮件标题和正文、由完成记录形成的日常规律依据摘要、个人画像及行为说明，以及用户主动请求重新摘要的会议转写文本。将个人画像上下文用于待办排序时，也会检查个人画像同意。会议同意是与其他数据同意分开的设备级设置，不会仅因连接或 iCloud 恢复而开启。
- **订阅连接测试**：用户在设置中主动请求时，仅向 OpenAI 发送简短的固定测试消息，以确认模型提供情况和响应是否完成。不使用已保存的应用数据，也不使用待办、邮件、日常规律或个人画像共享同意。需要已连接账户的订阅使用权限，但即使外部分析提供商处于关闭状态，也可以测试，且可能消耗部分订阅限额。该测试不会授权实际应用数据分析的启用或同意。
- **模型**：基础请求使用 `gpt-6-luna`；邮件重要内容、日常规律、个人画像/行为说明的明确高级再次请求使用 `gpt-6.1-sol`。不会将账户中不可用的模型自动替换为其他模型。
- **账户模型列表**：使用已连接账户的 OAuth 令牌查询模型列表，显示名称和模型 ID。此查询不进行推理，也不发送已保存的应用数据，且不保证其他 API 的使用权限。
- **按账户统计的本地使用量**：将已完成响应提供的输入、输出、缓存输入令牌数、响应 ID 去重记录及统计开始日期保存在此设备上。以 subject 的 SHA-256 哈希区分账户，指标中不保存原文、邮箱地址或身份验证令牌。缓存输入是输入令牌的一部分。不估算缺失数字；这些数据不是账户整体、其他应用或每月使用量，也不是账单金额或剩余限额。不会通过 iCloud 同步，普通断开连接后仍会保留，删除所有连接记录时才会清除。不会猜测无法通过公开连接协议确认的订阅计划。
- **邮件的自动路径**：使用可用的 Apple Intelligence 分析完整正文；失败或不受支持时，可通过设备内规则仅显示事实摘要。仅根据成功正文分析中的待审核/处理项目建议待办；没有此类项目或无法确认时，不会根据标题或摘要随意创建待办。邮件和会议来源的待办不参与自动外部排序。所选邮件的 OpenAI 正文分析，仅在同意邮件共享后，由用户主动点击相应请求按钮时进行。
- **会议与日历边界**：会议的自动摘要、转写和说话人分析在设备内处理。仅在单独同意会议共享后，用户主动执行**使用 ChatGPT 重新摘要 → 发送并重新摘要**时，才向 OpenAI 发送所选会议的转写文本、摘要语言、格式和撰写指令。多来源会议须所有来源均已准备就绪，且可能包含来源名称和说话人标记。不发送原始音频、其他会议、个人词汇表或先前摘要。不发送独立日历事件上下文的标题和备注，但从外部日历导入并确认的待办标题、备注适用一般待办共享同意。
- **响应与取消**：向公开 Responses API 以 `store:false`、`stream:true` 发出请求，且仅使用完成的响应。对于会议，仅将通过转写依据验证的成功结果替换已保存摘要及待审核候选，不改变原始音频、转写或已添加待办。提供商的保留和数据使用遵循 OpenAI 政策，不保证零保留。撤回同意、停用提供商、更换账户或退出登录，会取消相关进行中的请求，并阻止迟到响应的应用。处理中修改原文、摘要设置或删除记录，也会阻止应用；未完成、失败或取消的响应会保留现有结果。
- **与开发者控制台跟踪的区别**：这是发布构建中不存在的开发诊断功能。Debug/Debug-QA 记录开始、HTTP 状态、失败阶段和错误类型，不记录正文。仅当开发者在会议重新摘要界面主动开启**记录完整请求和响应（Debug）**或设置 `PIEROOT_LLM_DEBUG=1` 时，才向控制台输出实际 OpenAI 请求 JSON 及收到的响应、错误正文。界面开关不保存、不同步，默认关闭。日志可能包含所选转写、邮件等请求内容，不得公开。不记录身份验证标头、Cookie 或 URL 查询参数，也会遮盖请求使用的访问令牌的直接反射值。应用不会将该输出放入单独文件、iCloud、第 1-6 节的诊断存储库或错误报告，也不会自动发送。开发工具保留的控制台记录须由开发者另行管理和删除。

### 1-6. 经用户同意的错误诊断（可选）

- **收集项目**：错误发生时间和重复次数，源文件、行号、函数，错误域、代码、类型、消息（去除文件路径和邮箱地址，限制为 300 字符）及底层错误链；错误发生时的应用版本、构建、操作系统版本及构建、应用运行状态、功能设置、语言、从设备语言设置派生的国家/地区、时区、UTC 偏移、日历及 24 小时制设置；报告准备时的设备型号标识符、内存、存储空间、屏幕尺寸、处理器数量、语言、地区和时区；应用留下的近期错误日志（最多 300 条、30 分钟），以及 Apple 之后可能提供的崩溃、卡顿和内存终止诊断。国家/地区源自设备语言设置，而非实际位置。
- **排除项目**：实际位置、GPS 位置、设备名称、录音、转写文本、待办、邮件正文/标题/地址、个人画像、账户标识符、身份验证令牌。
- **同意及存储**：仅在用户于应用内明确允许时，才在设备本地排除备份且受文件保护的存储库中保留有限数量的记录。撤回同意或删除本地诊断日志时立即删除。
- **传输及事先审核**：应用不会自动通过网络发送诊断日志。设备本地审核界面显示准备好的完整报告原文，以及实际磁盘容量、系统运行时长、启动时间和各错误时刻的快照。在支持应用内反馈的版本中，仅当用户选择在错误报告中包含此报告，并明确批准最终发送时，才将同一报告通过 HTTPS 发送至 SIFT 私有接收箱。无需设置邮件应用或登录服务账户。只有确认服务器接收成功后，才将相应本地诊断标记为已处理。取消审核或发送失败时保留本地诊断。旧版本通过邮件或共享表单发送至用户所选的接收者，不属于自动接收。
- **Apple 系统诊断**：MetricKit/App Store Connect 诊断可能根据 Apple 和设备设置延迟提供或不提供，并不能捕获所有强制终止。

#### 应用内错误报告及功能建议

- **发送项目与目的**：用户亲自填写的类型、标题、说明，应用版本、构建、平台、OS 版本、所选语言，以及防止重复接收的随机提交 ID，用于错误调查和功能改进。仅当用户在错误报告中另行选择包含诊断时，才附加上述准备好的诊断报告。功能建议不附加诊断。
- **用户选择**：仅在用户审核输入内容和附件信息后，主动发送时才上传。无需连接账户或邮箱，也无需填写联系方式；不会自动附加已保存的待办、邮件、音频、健康记录或身份验证信息。请勿在自由输入栏中填写个人信息、密码或邮件原文。
- **处理与访问**：Cloudflare Workers 处理请求，并保存至 D1 的私有接收箱。仅运营者可在身份验证后查看、分类和删除，不会发布为公开 GitHub issue。接收编号仅用于确认接收，不提供公开查询或个别回复。
- **保留**：接收内容、诊断附件及运营备注在接收 30 天后从查询对象中排除，并由每日定时任务删除。正常运行时，从到期至下一次定时任务最多可能相差 24 小时；提供商发生故障时，删除可能进一步延迟。运营者可提前删除。D1 免费计划的时间点恢复历史中，删除前的数据最多可能残留 7 天，且无法通过运营接收箱公开查询。删除本地日志或应用，不会立即删除已经发送的接收内容。提出删除请求时，请提供接收编号。
- **防滥用及网络信息**：Cloudflare 在处理传输时会处理 IP 地址等网络信息。SIFT 接收数据不存储原始 IP 或永久设备标识符。仅保留由每日密钥通过 HMAC 生成的网络限流键，最多 2 天；不将提交正文、诊断或管理员密钥记录到应用程序日志。无需登录不代表对网络提供商而言也完全匿名。
- **服务限额**：达到免费服务限额、每日接收量、正文大小或存储量限制，或网络中断时，发送可能失败。应用不会在未经服务器确认接收的情况下显示成功，而会保留填写界面以供用户重试。

### 1-7. 会议录音、应用音频、说话人区分及离线重新转写（可选）

- **处理项目及平台边界**：处理所选麦克风音频、经系统共享 picker 批准的应用/屏幕输出（可能包含对方发言或其他应用声音）、各来源的转写文本、说话人时间区间、用户名称/分配、on/off 及选择边界。Mac Catalyst 路径支持最多 4 个分别批准的目标及独立麦克风；iOS 27 iPhone 路径为单一整个屏幕选择及麦克风。iPhone 无法选择单个应用或人员，iOS 26.x 和 simulator 不支持应用音频。该路径说明不代表已验证实际会议应用/设备的通话采集。**不保存屏幕视频或照片**。请确认第三方对话的录音同意及当地规定。尚未实现提供商直接接收器，提供商 API 的条件及平台边界另行适用。
- **会议活动检测（Mac，可选）**：用户开启会议检测后，会在设备内存中检查获准应用的进程、应用标识符、显示名称以及输入/输出音频是否活动，并显示会到期的录音建议。检测不会收集浏览器网站、会议内容或音频，检测本身也不会开始录音。检测及目标应用选择按设备设置，不会通过同步开启。主动开始录音、所需系统权限及参与者同意均为独立事项。
- **独立来源控制**：分别控制麦克风和已批准目标是否录音，应用不会改变其他会议应用的发送静音、收听设备或音量。各来源以 unity gain 的独立 FLAC 保存，不在父记录中保存混音文件或合并转写。整体播放与交叉对话时间线按共同时间对齐已保存来源，在设备内以只读方式合成，不替换原始内容，也不发送至额外服务器。无法消除扬声器声音重新进入麦克风的情况，建议使用耳机。各轨道独立隔离，避免一条轨道失败影响其他轨道的原始音频和转写，不保证采集特定应用的实际通话音频。
- **模型安装及处理**：仅在用户于设置 → 会议中主动点击安装时，才下载 Hugging Face 的固定公开文件，并验证大小及 SHA-256。说话人区分默认采用 Nemotron，是否使用另行选择。即使使用设置已开启，也不会自动安装模型，且会保留关闭选择。Whisper 仅用于录音结束后的可选测试版重新转写，可能需要额外电量和时间。自动语言模式在录音中也只保存原始音频，结束后再检测语言并转写。安装请求不包含会议音频、转写或说话人信息。Nemotron 实时/最终说话人分析及 WhisperKit 已存音频重新转写均在设备内处理。基于 pyannote Community-1 的 FBank/WeSpeaker 是用于轨道内部 ID 关联的辅助提取器，不替代 Nemotron。保留 [CC BY 4.0 范围及 pyannote/WeSpeaker/FluidInference 署名](https://huggingface.co/FluidInference/speaker-diarization-coreml/blob/df2625ac79a7ac6b65ad868fee6d80f320da4232/NOTICE.md)。嵌入向量仅在各轨道分析期间保留在内存中，不存储、不同步，也不将不同轨道/会议中的人员关联。仅共享不可变权重，各 worker 的可变模型/状态相互分离，所有实时轨道结束后依次执行最终处理。
- **原文、存储及恢复**：新录音以父记录及带唯一 ID 的各来源子记录保存在本地。保留各子记录的 16 kHz mono FLAC、manifest、Apple 原文、离线/校订转写、Nemotron 实时/最终说话人 ID、名称/分配、来源状态和选择信息，以及相对父记录的开始偏移。轨道时间以来源开始时的 0 为基准。活动/结束日志在中断时恢复可读取的连续音频 prefix，不会凭空补齐丢失的音频或转写。既有已完成记录保持为独立记录。逐轨播放、编辑、重新处理、导出及全部原始 ZIP（`meeting.json`、`tracks/<child>/audio/` 中的 FLAC 和 `manifest.json`）由用户选择执行，向外部共享时，音频及来源信息可能传给所选接收者。同意完整 iCloud 存储后，会议记录、原始音频及恢复信息也会复制至同一 Apple 账户。排除在 Firebase 快照之外，不会为重新转写或说话人分析发送至外部 AI 服务。不将原文或音频样本记录到诊断日志。
- **本地文件导入**：以只读方式打开用户在系统文件选择器中所选的音频，转换并保存为设备内会议音频。不更改原始文件及原始位置，记录中仅保留文件的基本名称。导入本身不请求麦克风权限、模型下载或服务器上传。如果文件提供商下载原始文件，则适用该提供商的政策。模型未安装或转写失败后，本地音频仍会保留供重试；删除会议时，删除应用内的副本。
- **明确执行的音频下载与删除**：用户可通过系统保存窗口导出所选来源的原始 ZIP 或 WAV，或所有来源的原始 ZIP。Mac 为执行该保存操作，仅获得用户所选目标文件的读写权限，不请求全磁盘或任意文件夹访问权限。导入的原始文件仍仅以只读方式访问。确认删除会议记录时，将同时删除会议所属的全部来源、转写、摘要、应用内原始音频及恢复资料，保留已添加的待办和用户保存到外部的下载副本。

### 1-8. 基于完成记录的日常规律及日程建议（可选）

- 开启设备内学习并主动分析时，将最近 90 天已完成的手动待办按相同的规范化标题分组。需要至少 3 天的完成依据，并排除邮件、会议、外部日历、待审核和已删除项目。
- 完成勾选记录不能证明实际活动执行时间、持续时长、服药情况或健康状况。应用显示依据数量、期间、周期、偏好时间及不确定性，仅依据用户确认和修改后的日常规律提出待办建议。
- 在受保护的本地文件中记录接受、拒绝、推迟、与现有项目的重复检查、已批准日程及待办 ID。检查可用时间、实际截止时间、应用日程和有权限的日历冲突，仅在用户批准时段后保存开始日期和截止日期。新提醒和日历导出须另行选择。
- 关闭学习后，学习和建议停止；选择全部删除后，将删除日常规律、依据和反馈。已经批准的待办须另行删除。

### 1-9. ChatGPT 连接信息（可选）

- 通过官方 SIWC 公共客户端流程管理账户标识、注册 ID、设备级 host ID、授予范围、到期时间及 OAuth 令牌。同意完整 iCloud 存储范围并确认当前 Apple 账户后，通过 iCloud 钥匙串同步注册和令牌，以便同一账户的其他完整存储安装恢复。既有仅设备连接也会依照此政策复制，host ID 保持接收设备自身的唯一值。iCloud 停用或仅本地构建不会获取或上传云端连接。提供商启用和数据传输同意在各设备上单独设置。
- 退出登录会清除令牌并尝试远程撤销，但保留用于重新连接的注册。删除所有连接记录会删除注册、host ID 和凭据。网络失败时不保证完成远程撤销，用户可在 ChatGPT 设置中管理应用权限。
- iCloud 钥匙串实际传播时间由 Apple 决定。应用在激活和请求前重新读取连接，但不保证即时传播或离线恢复。轮换令牌的刷新所有权标记与凭据一起同步，刷新仅在批准连接的一处安装上执行。其他设备可在到期前使用令牌，到期后须在原设备打开 SIFT 等待刷新及同步，或在当前设备明确重新连接。失败令牌的设备级隔离不同于退出登录或共享删除，迟到的有效令牌会被接受。明确远程撤销共享会话，也可能影响其他设备上的同一连接。
- 本地登录保存后若传播中断，会在设备上记录待发布状态及基准哈希，而不是机密原文。与其他设备的变更冲突时，会保留本地及共享版本，并在同步状态中告知，不会自动将本地登录恢复为旧值。这些运营元数据不会作为其他设备的设置恢复。
- [官方适用范围](https://developers.openai.com/siwc/token-sharing-open-source)为开源、本地托管应用，付费或远程托管分发需要 OpenAI 另行批准。适用各计划、账户、模型的权限和使用限额。

### 1-10. 实际健康及运动记录连接（可选）

- **范围及权限**：仅对用户在设置中明确连接的项目，读取 HealthKit 最近最多 90 天的运动或服药记录。各项目独立连接，不请求写入、临床记录或后台递送权限。服药使用 iOS 26 或更高版本的实际服用（`taken`）事件及供用户显示的药名，不收集或推断剂量、单位、处方日程或服药依从性。Mac Catalyst 不支持读取健康记录，因此停用此连接。权限请求完成不等于获准读取的证据，也不会以空结果判定是否被拒绝。
- **本地处理及批准**：来源应用默认未获批准。以获准来源至少 4 天的记录及 80% 以上的周期、时间一致性生成候选，须由用户审核并确认标题、周期、时间、基准日期和时区后才启用。不会合并多个药品或来源，也不会把每天多次服药解释为每日一次处方。不提供医疗建议、处方/剂量更改或漏服/补服建议。
- **存储**：原始记录的有限投影、来源批准、候选、生成同意及去重标记保存在受文件保护且排除备份的设备专用存储库，不发送至 CloudKit、Firebase 或 OpenAI。生成的健康来源待办也排除在自动 OpenAI 分析、一般行为/个人画像依据、完成勾选学习、自动日历添加和自动提醒分配之外。
- **待办生成及同步**：除来源批准和日常规律确认外，还需单独同意自动生成。由于生成待办的标题和日程也可能透露健康信息，因此根据 [Apple 政策](https://developer.apple.com/app-store/review/guidelines/#health-and-health-research)，将其排除在 iCloud 完整存储之外。它们会包含在用户主动执行的加密 Firebase 快照中，并在生成同意前告知此边界。仅创建下一次未来发生项，不追溯生成过去日程。用户在个别待办中主动选择的日历导出和提醒，是独立的用户操作。
- **停止及删除**：断开连接会停止/删除对应项目的读取、本地依据及来源批准。清除记录会清除所有连接、生成同意、原始数据和候选，但保留现有待办及非临床去重标记。仅全部重置才会清除标记，并会确认现有待办仍保留、可能再次生成。应用不会修改 HealthKit 原始记录或撤回 OS 读取权限。
- **健康信息使用限制**：HealthKit数据及由此生成的健康来源待办等派生信息不用于广告或第三方营销。

| 日常规律、依据、反馈 | 直至用户删除 | 本地删除；使用完整存储时同步单独删除记录。已批准的待办另行删除 |
| OpenAI 凭据 / 用于重新连接的注册、host ID | 凭据在退出登录时删除，重新连接记录保留至全部删除时 | 删除 Keychain 的本地及同步连接信息，并尝试远程撤销；host ID 为设备专用 |
| iCloud 数据 | 直至在应用中删除并同步，或在 Apple 账户的各应用存储空间中删除 | 如需停止复制，关闭应用的完整存储；远程资料须在 OS 的 iCloud 存储空间管理中另行删除；仅关闭功能不会删除远程资料 |
| 本地应用数据 | 删除应用或用户主动删除时 | 从设备存储库删除 |
| 待办活动记录与删除审计记录 | 活动发生后120天；删除审计记录在删除后120天 | 从设备和 iCloud 自动删除 |
| 经用户同意的本地诊断日志 | 直至撤回同意或用户在应用中删除 | 删除设备本地诊断存储库 |
| 已发送的错误报告、功能建议、诊断附件、运营备注 | 接收后 30 天，运营者可提前删除 | 从私有接收箱定期删除（提供商故障或定时任务延迟时可能延后） |
| 每日 HMAC 网络限流键 | 最多 2 天 | 定期删除 |

## 6. 用户权利及行使方式

用户可随时通过以下方式行使权利。

- **删除待办、个人画像**：在应用内直接删除。
- **删除会议记录**：在应用内会议记录中删除本地模型、录音、转写、说话人及恢复资料，使用完整存储时同步删除记录。
- **断开邮件集成**：设置 → 邮件集成 → 断开连接。删除设备凭据并撤销允许的共享，与删除已存邮件原文及撤销提供商权限不同。
- **删除日常规律、停止学习**：设置 → 日常规律与建议 → 关闭学习，或选择全部删除，清除日常规律、依据和反馈。
- **撤回 OpenAI 同意、删除连接**：设置 → AI → OpenAI · ChatGPT → 关闭各类数据同意、退出登录或删除所有连接记录。
- **撤回日历权限**：iOS 设置 → 隐私 → 日历 → 停用 SIFT。
- **停止 iCloud 复制**：设置 → iCloud 同步 → 关闭完整存储。不会删除当前设备、其他设备或已经上传的资料。
- **删除所有数据**：在应用中清除资料或删除应用以移除本地资料。iCloud 资料通过同步删除，或在 OS 的 Apple 账户 → iCloud → 管理存储空间中另行删除。
- **请求删除已发送反馈**：向下述联系方式提供接收编号，经私有接收箱确认后删除。该操作独立于删除应用本地数据。

如需查阅、更正、删除信息或停止处理，请联系 **pieroot.02@gmail.com**，我们将及时处理。

## 7. 数据安全

- 邮箱 OAuth、Gmail/Outlook IMAP 应用专用密码、ChatGPT 注册/令牌及学习标识密钥保存在 Keychain。同意完整存储并确认当前 Apple 账户后，复制至 iCloud 钥匙串；设备 host ID 及运行机密的访问控制为设备专用。不会将令牌或密码原文记录到 UserDefaults、一般设置同步或诊断日志。
- 邮件、会议和日常规律原始数据的权威副本保留在受保护的本地存储库，仅在同意扩大范围后复制至 iCloud。向 OpenAI 发送适用上述第 1-5 节的单独同意和主动请求。诊断报告不包含正文、日常规律依据或身份验证令牌。
- iCloud 数据使用 Apple 提供的加密基础设施（传输中及静态加密）。
- 应用不使用非豁免加密（`ITSAppUsesNonExemptEncryption = NO`）。

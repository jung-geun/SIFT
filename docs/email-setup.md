# 이메일 연결하기

SIFT의 이메일 연결은 **IMAP 방식**입니다. 실제 연결이 확인된 **Gmail**을 기준으로 안내합니다. Google에서 앱 비밀번호를 만든 뒤 SIFT에 입력하면 받은편지함을 확인하고 메일 속 요청을 할 일로 정리할 수 있습니다.

메일 연결은 선택 사항입니다. 연결하지 않아도 기본 할 일 관리는 사용할 수 있습니다.

## 1. Google 계정의 2단계 인증을 켜세요

1. 연결할 Gmail 주소로 [Google 계정](https://myaccount.google.com/)에 로그인합니다.
2. **보안 및 로그인 → Google에 로그인하는 방법 → 2단계 인증**으로 이동합니다.
3. 화면 안내에 따라 2단계 인증을 켭니다. 이미 사용 중이라면 다음 단계로 넘어가세요.

앱 비밀번호를 만들려면 2단계 인증이 필요합니다. 자세한 순서는 [Google의 2단계 인증 안내](https://support.google.com/accounts/answer/185839?hl=ko)를 참고하세요.

## 2. SIFT용 앱 비밀번호를 만드세요

1. 같은 계정으로 [Google 앱 비밀번호 관리](https://myaccount.google.com/apppasswords)를 엽니다. 본인 확인을 요청하면 완료합니다.
2. `SIFT iPhone`처럼 앱과 기기를 알아볼 수 있는 이름을 입력하고 **만들기**를 선택합니다.
3. 표시된 **16자리 앱 비밀번호**를 복사합니다.

**Google의 일반 로그인 비밀번호와는 다릅니다.** 일반 비밀번호, 2단계 인증 코드, 복구 코드를 SIFT에 입력하지 마세요. 여기서는 Google이 별도로 만든 앱 비밀번호만 사용합니다.

앱 비밀번호 메뉴가 보이지 않으면 아래 [연결 문제 해결](#troubleshooting)을 확인하세요. 연결을 위해 2단계 인증이나 고급 보호를 끄지 마세요.

## 3. SIFT에서 Gmail을 연결하세요

1. SIFT의 **설정 → 이메일 연동**을 엽니다.
2. **Gmail IMAP 연결** 항목을 펼칩니다.
3. **Gmail 이메일 주소**에 앱 비밀번호를 만든 계정의 전체 주소를 입력합니다.
4. **Google App Password**에 앱 비밀번호를 붙여넣습니다.
5. **자동 백그라운드 메일 불러오기**는 필요할 때만 켜세요. 꺼둔 채 연결해도 됩니다.
6. **Gmail IMAP 연결** 버튼을 누릅니다. 기기에서 본인 확인을 요청하면 완료합니다.
7. 확인이 끝나면 **Gmail 계정** 행에 **연결됨**이 표시됩니다.

서버 설정은 자동으로 적용됩니다. Gmail 서버는 `imap.gmail.com`, 포트는 `993`이며 SSL/TLS로 연결합니다. 앱에서 서버나 포트를 따로 입력할 필요는 없습니다. 개인 Gmail은 [IMAP이 항상 켜져 있으므로](https://support.google.com/mail/answer/7126229?hl=ko) 웹 설정에서 별도로 활성화하지 않아도 됩니다.

## 연결한 메일을 확인하세요

**메일** 탭에서 받은편지함을 확인하세요. 바로 새 메일을 가져오려면 **설정 → 이메일 연동**의 연결된 **Gmail 계정** 행을 길게 눌러 **지금 메일 확인**을 선택합니다.

- **자동 백그라운드 메일 불러오기**는 기본적으로 꺼져 있습니다. 켜면 기기를 한 번 잠금 해제한 후에는 잠겨 있어도 저장된 앱 비밀번호를 사용할 수 있습니다. 안내된 보안 위험을 확인한 뒤 선택하세요.
- **메일 자동 분석**은 메일에서 할 일 후보를 정리하는 별도 설정입니다. 필요하지 않으면 꺼두세요.
- **자동 동기화 시각과 메일 분석 기간**을 조절할 수 있습니다. 기기 상태와 네트워크에 따라 자동 실행 시점은 달라질 수 있습니다.

**읽음 처리와 휴지통 이동은 원래 Gmail에도 반영됩니다.** 목록을 불러오는 것만으로 읽음 처리되지는 않지만, 읽지 않은 메일을 열면 읽음 처리를 요청합니다. 휴지통으로 옮길 때도 원본 메일에 영향을 줍니다.

## 연결을 해제하거나 기기를 바꿀 때

앱 비밀번호는 **이 기기의 Keychain**에 저장되며 iCloud로 동기화하지 않습니다. 새 기기에서는 그 기기용 앱 비밀번호를 만들어 연결하세요.

1. **설정 → 이메일 연동**에서 연결된 계정 행을 길게 누르거나 왼쪽으로 밀어 **연결 해제**를 선택합니다.
2. SIFT에서 이 기기의 앱 비밀번호와 연결 계정 정보가 삭제됩니다.
3. [Google 앱 비밀번호 관리](https://myaccount.google.com/apppasswords)에서도 사용하지 않는 SIFT용 비밀번호를 **삭제**하세요.

**SIFT에서 연결을 해제하는 것과 Google에서 앱 비밀번호를 취소하는 것은 별개입니다.** 기기를 잃어버렸다면 Google에서 먼저 삭제하세요. 연결 해제가 원본 메일이나 이미 저장한 메일·할 일을 일괄 삭제하지는 않습니다.

<h2 id="troubleshooting">연결이 잘되지 않을 때</h2>

- **앱 비밀번호 메뉴가 없어요.** 올바른 계정인지, 2단계 인증이 켜져 있는지 확인하세요. 직장·학교 계정, 보안 키만 사용하는 2단계 인증, 고급 보호 프로그램에서는 메뉴가 없을 수 있습니다. 조직 계정은 관리자에게 앱 비밀번호와 IMAP 사용 가능 여부를 문의하세요. [Google 공식 안내](https://support.google.com/accounts/answer/185833?hl=ko)
- **비밀번호를 거부해요.** 일반 비밀번호가 아닌 앱 비밀번호인지, 발급 계정과 입력 주소가 같은지 확인하세요. Google의 일반 비밀번호를 변경하면 기존 앱 비밀번호도 취소되므로 새로 만들어야 합니다.
- **저장된 계정이 미연결로 보여요.** 네트워크나 기기 본인 확인 문제를 해결한 뒤 **다시 연결**을 누르세요. 비밀번호가 취소됐다면 **App Password 교체**를 선택해 새 앱 비밀번호를 입력합니다.
- **시간 초과나 보안 연결 오류가 나요.** 인터넷 연결을 확인하고 다른 네트워크에서 시도하세요. 조직 네트워크라면 IMAP 포트 `993`이 차단돼 있는지도 확인하세요.
- **연결됐는데 메일이 없어요.** Gmail 웹에서 같은 계정의 받은편지함을 확인한 뒤 SIFT에서 수동으로 새 메일을 가져오세요. 받은편지함이 비어 있어도 정상 연결할 수 있습니다.

도움이 필요하면 오류 문구와 발생 상황만 알려주세요. **일반 비밀번호·앱 비밀번호·인증 코드·복구 코드는 문의나 피드백에 보내지 마세요.** 화면을 공유할 때는 이메일 주소와 메일 내용도 가려주세요.

<h2 id="outlook">Outlook 및 다른 메일 제공자</h2>

SIFT 설정에는 **Outlook IMAP 연결** 항목도 있지만, 현재 앱 비밀번호 방식은 Microsoft가 요구하는 인증 방식과 맞지 않아 연결 성공을 보장하지 않습니다. Gmail 절차를 Outlook에 그대로 적용하지 마세요.

- **Outlook.com 개인 계정**은 Modern Authentication을 요구합니다. [Microsoft 인증 안내](https://support.microsoft.com/en-us/office/modern-authentication-methods-now-needed-to-continue-syncing-outlook-email-in-non-microsoft-email-apps-c5d65390-9676-4763-b41f-d7986499a90d)
- **Microsoft 365 회사·학교 계정**의 Exchange Online은 IMAP 기본 인증을 차단하며, 앱 비밀번호도 이를 우회하지 못합니다. [Microsoft의 인증 정책](https://learn.microsoft.com/en-us/exchange/clients-and-mobile-in-exchange-online/deprecation-of-basic-authentication-exchange-online)

이 제한은 IMAP 자체가 아니라 제공자의 인증 정책에 따른 것입니다. 일반 Microsoft 계정 비밀번호를 대신 입력하거나 보안을 낮추지 마세요. 현재 SIFT에는 다른 제공자의 서버를 직접 입력하는 범용 연결 화면은 없습니다.

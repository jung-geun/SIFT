## 1. 수집하는 정보 및 목적

### 1-1. 직접 입력 정보

| 항목 | 목적 |
|------|------|
| 할 일 제목·메모·마감일·태그·우선순위 | 할 일 관리 |
| 페르소나 유형·설명 | AI 우선순위 개인화 |

### 1-2. 자동 생성·수집 정보

| 항목 | 수집 경위 | 목적 |
|------|-----------|------|
| Audit 이벤트 (등록·완료·삭제 시각·출처) | 할 일 처리 시 자동 기록 | 행동 패턴 분석 |
| 행동 패턴 분석 결과 (시간대·태그별 완료율 요약) | 온디바이스 AI 또는 사용자가 선택한 Gemini 분석 | AI 우선순위 조정 |
| 앱 설정값 (AI 제공자 선택, 이메일·캘린더 옵션 등) | 설정 저장 | 기능 동작 |

### 1-3. Gmail 연동 (선택, 사용자 명시적 동의 후 활성화)

- **수집 항목**: 받은편지함 메시지 제목·발신자·스니펫·본문 (읽기 전용, `gmail.readonly` 권한)
- **목적**: 마감·일정 관련 이메일에서 할 일 자동 추출
- **저장 위치**: 기기 내 별도 로컬 전용 저장소 (기본적으로 이메일 본문은 iCloud 동기화 및 외부 전송되지 않습니다)
- **OAuth 토큰**: 기기의 Keychain에만 저장
- **Google API**: Google LLC가 운영하는 Gmail REST API (`gmail.googleapis.com`)를 통해 데이터를 읽습니다.

### 1-4. 캘린더 연동 (선택, 시스템 권한 허용 후 활성화)

- **수집 항목**: 캘린더 이벤트 (EventKit, 읽기·쓰기)
- **목적**: 마감일이 있는 할 일을 시스템 캘린더에 자동 등록하고, 캘린더 일정을 할 일로 가져오기
- **처리 위치**: 기기 내 시스템 캘린더 프레임워크(EventKit). 앱 외부 서버로 전송하지 않습니다.

### 1-5. 할 일 우선순위 정렬 AI

- 기본값: **온디바이스 AI**(Apple Foundation Models 또는 MLX Qwen) 사용
- **Gemini 제공자 선택 시**: 할 일 제목·메모·마감일·페르소나·캘린더 컨텍스트가 사용자의 API 키로 Google Gemini API에 전송될 수 있습니다.
- **Gemini 메일 본문 분석 opt-in 시**: Gmail 제목·발신자·본문이 Gemini API로 전송될 수 있습니다.
- **이메일 본문 기본값**: 별도 동의가 없으면 기기 밖으로 전송하지 않습니다.

### 1-6. 사용자 동의형 오류 진단 (선택)

- **수집 항목**: 오류 발생 시각·반복 횟수, 오류가 발생한 기능 위치와 소스 파일·줄 번호, 오류 도메인·코드·유형·메시지(파일 경로와 이메일 주소 제거, 300자 제한)와 하위 오류 사슬, 앱 버전·빌드·설치 경로, 운영체제 버전, 기기 모델 식별자·메모리·저장 공간·화면 크기·프로세서 수, 언어·지역·시간대, 발열 상태·저전력 모드·앱 메모리 사용량·앱 실행 상태, 기능 설정 On/Off 값, 앱이 남긴 최근 오류 로그(최대 300건, 30분), Apple이 나중에 제공할 수 있는 충돌·멈춤·메모리 종료 진단
- **제외 항목**: 음성 녹음, 전사문, 할 일, 이메일 본문·제목·주소, 페르소나, 계정 식별자, 인증 토큰
- **동의 및 저장**: 사용자가 앱 내에서 명시적으로 허용한 경우에만 기기 로컬의 백업 제외·파일 보호 저장소에 제한된 개수로 보관합니다. 동의를 철회하거나 로컬 진단 로그를 삭제하면 즉시 삭제합니다.
- **전송**: 앱은 진단 로그를 자동으로 네트워크 전송하지 않습니다. 사용자가 메일 또는 공유 시트에서 보고서를 검토하고 보내는 경우에만 선택한 수신자에게 전송됩니다.
- **Apple 시스템 진단**: MetricKit/App Store Connect 진단은 Apple과 기기 설정에 따라 지연되어 제공되거나 제공되지 않을 수 있으며, 모든 강제 종료를 포착하지 않습니다.

## 2. 정보 저장 위치

| 저장소 | 저장 항목 |
|--------|-----------|
| 기기 내 로컬(SwiftData) | 할 일, 페르소나, Audit 이벤트, 분석 결과 (iCloud 비활성 시) |
| 기기 내 로컬 전용(별도 emailContainer) | Gmail 메시지 전체 (iCloud 동기화 완전 제외) |
| Apple iCloud CloudKit 비공개 DB (선택) | 할 일, 페르소나, Audit 이벤트, 분석 결과 (iCloud 활성 시) |
| iCloud Key-Value Store (선택) | 앱 설정값 (AI 제공자 선택 등) |
| 기기 Keychain | Gmail OAuth 액세스 토큰·리프레시 토큰 |
| 기기 UserDefaults | 캐시된 설정값 |
| 기기 내 로컬 진단 저장소 (선택) | 동의한 오류 시각·위치·코드·유형·메시지, 기기 사양·설정 스냅샷, 최근 앱 오류 로그 및 제한된 Apple 시스템 진단 — iCloud·백업 제외 |

**이메일 본문 관련 명확화**: 이메일 메시지(본문 포함)는 기본적으로 기기 내 별도 로컬 저장소에만 보관되며, iCloud 동기화 및 외부 전송되지 않습니다. 사용자가 Gemini 제공자 또는 Gemini 메일 본문 분석을 명시적으로 켠 경우에만 선택된 TODO·페르소나·캘린더 컨텍스트와 선택적 Gmail 본문이 사용자의 API 키로 Google Gemini API에 전송될 수 있습니다. iCloud를 활성화하면 할 일 등 동기화 항목은 사용자의 **비공개** CloudKit 데이터베이스에 저장됩니다.

## 6. 이용자의 권리 및 행사 방법

이용자는 언제든지 아래 방법으로 권리를 행사할 수 있습니다.

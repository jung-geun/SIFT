# Connect your email

SIFT connects to email using **IMAP**. This guide covers **Gmail**, for which a working connection has been confirmed. Create an app password with Google and enter it in SIFT to view your inbox and turn email requests into tasks.

Connecting email is optional. You can use basic task management without connecting it.

## 1. Turn on 2-Step Verification for your Google account

1. Sign in to your [Google account](https://myaccount.google.com/) with the Gmail address you want to connect.
2. Go to **Security & sign-in → How you sign in to Google → 2-Step Verification**.
3. Follow the instructions to turn on 2-Step Verification. If you already use it, continue to the next step.

You need 2-Step Verification to create an app password. For detailed steps, see [Google's 2-Step Verification guide](https://support.google.com/accounts/answer/185839?hl=ko).

## 2. Create an app password for SIFT

1. Open [Google App passwords](https://myaccount.google.com/apppasswords) with the same account. Complete identity verification if prompted.
2. Enter a name that identifies the app and device, such as `SIFT iPhone`, and select **Create**.
3. Copy the **16-character app password** that appears.

**This is different from your regular Google sign-in password.** Do not enter your regular password, a 2-Step Verification code, or a recovery code in SIFT. Use only the separate app password generated by Google here.

If you do not see the app password menu, check [troubleshooting](#troubleshooting) below. Do not turn off 2-Step Verification or Advanced Protection to connect.

## 3. Connect Gmail in SIFT

1. Open **Settings → Email integration** in SIFT.
2. Expand **Connect Gmail IMAP**.
3. Under **Gmail email address**, enter the full address of the account used to create the app password.
4. Paste the app password into **Google App Password**.
5. Turn on **Automatic Background Mail Fetch** only if you need it. You can connect with it turned off.
6. Press **Connect Gmail IMAP**. Complete identity verification on your device if prompted.
7. Once verification finishes, the **Gmail account** row shows **Connected**.

Server settings are applied automatically. The Gmail server is `imap.gmail.com` on port `993`, using SSL/TLS. You do not need to enter a server or port separately in the app. For personal Gmail accounts, [IMAP is always on](https://support.google.com/mail/answer/7126229?hl=ko), so there is no need to enable it separately in web settings.

## Check your connected email

View your inbox in the **Mail** tab. To fetch new mail immediately, press and hold the connected **Gmail account** row in **Settings → Email integration** and select **Check Email Now**.

- **Automatic Background Mail Fetch** is off by default. If you enable it, the saved app password can be used while the device is locked after it has been unlocked once. Review the stated security risks before choosing this option.
- **Automatic email analysis** is a separate setting that suggests tasks only from Needs Review/Action items in the full body. If there are no such items, no tasks are suggested automatically; you can enter and save one manually.
- Message lists and full bodies are saved on the device when the app becomes active and periodically, independently of the automatic analysis setting. Background fetching applies only to approved accounts. iOS determines when it can run, so no fixed interval is guaranteed.
- When automatic analysis is enabled, complete cached bodies are processed separately on the device. Background analysis applies only to approved accounts, and iOS decides when it runs. The analysis period does not limit IMAP list or body collection.

**Marking emails as read and moving them to the trash also affects the original Gmail messages.** Loading the list alone does not mark them as read; the app requests that an unread message be marked as read after its body has been retrieved. Even if marking it as read fails, you can still view the body already received. Moving an email to the trash also affects the original message.

## Disconnecting or changing devices

The app password is stored in **this device's Keychain**. Connection information can be restored when you explicitly consent to full iCloud storage and use the same Apple account and iCloud Keychain, but device-specific access approval and background permissions are not transferred. On a new device, check the connection information and approve the necessary access yourself, or create an app password for that device and connect.

1. In **Settings → Email integration**, press and hold the connected account row or swipe it to the left and choose **Disconnect**.
2. SIFT deletes this device's app password and connected account information.
3. Also **delete** any unused SIFT passwords in [Google App passwords](https://myaccount.google.com/apppasswords).

**Disconnecting in SIFT and revoking an app password in Google are separate actions.** If you lose a device, delete its app password in Google first. Disconnecting does not delete all original messages or all emails and tasks you have already saved.

<h2 id="troubleshooting">Troubleshooting your connection</h2>

- **There is no app password menu.** Check that you are using the correct account and that 2-Step Verification is on. The menu may not be available for work or school accounts, 2-Step Verification that uses only security keys, or the Advanced Protection Program. For organizational accounts, ask your administrator whether app passwords and IMAP are available. [Google's official guide](https://support.google.com/accounts/answer/185833?hl=ko)
- **The password is rejected.** Check that it is an app password, not your regular password, and that the account that issued it matches the address you entered. Changing your regular Google password also revokes existing app passwords, so you will need to create a new one.
- **A saved account appears disconnected.** Resolve any network or device identity verification issue, then press **Reconnect**. If the password has been revoked, choose **Replace App Password** and enter a new app password.
- **There is a timeout or secure connection error.** Check your internet connection and try a different network. On an organizational network, also check whether IMAP port `993` is blocked.
- **It is connected, but there is no mail.** Check the inbox for the same account in Gmail on the web, then manually fetch new mail in SIFT. A connection can succeed even if the inbox is empty.

If you need help, share only the error message and the circumstances in which it occurred. **Do not send regular passwords, app passwords, verification codes, or recovery codes in support requests or feedback.** Hide email addresses and message content when sharing a screen, too.

<h2 id="outlook">Outlook and other email providers</h2>

SIFT settings also include **Connect Outlook IMAP**, but the current app password method does not match Microsoft's required authentication method, so a successful connection is not guaranteed. Do not apply the Gmail steps directly to Outlook.

- **Personal Outlook.com accounts** require Modern Authentication. [Microsoft authentication guidance](https://support.microsoft.com/en-us/office/modern-authentication-methods-now-needed-to-continue-syncing-outlook-email-in-non-microsoft-email-apps-c5d65390-9676-4763-b41f-d7986499a90d)
- **Microsoft 365 work and school accounts** use Exchange Online, which blocks IMAP basic authentication. App passwords cannot bypass this restriction. [Microsoft authentication policy](https://learn.microsoft.com/en-us/exchange/clients-and-mobile-in-exchange-online/deprecation-of-basic-authentication-exchange-online)

This restriction comes from the provider's authentication policy, not IMAP itself. Do not enter your regular Microsoft account password instead or weaken your security. SIFT currently has no general-purpose connection screen for manually entering another provider's server.

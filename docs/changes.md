# 변경사항

현재 앱의 심사 제출 변경사항과 이미 공개된 버전 기록을 구분합니다. 심사 중인 기능이 다운로드한 출시 앱에 모두 제공된다는 뜻은 아닙니다.

<a id="version-1-0-14-13"></a>
## 1.0.14 (13) — 심사 접수·공개 전

**2026-11-01 확인 기준**, iOS/iPadOS·universal Mac Catalyst `1.0.14 (13)`의 서명 배포본 업로드와 처리가 완료됐고, 각각 빌드 13을 선택해 **Waiting for Review**로 심사 접수했습니다. 새로고침한 App Store Connect에서 두 플랫폼의 심사 대기 상태를 확인했습니다. **2026-11-09 00:00 KST 이후, Apple 승인 뒤 자동 공개**하도록 설정했으며 아직 승인·실제 공개 완료는 아닙니다. 기존 공개 앱은 두 플랫폼 모두 `1.0.13 (12)`의 Ready for Sale로 확인했습니다. [PR35](https://github.com/jung-geun/SIFT/pull/35)의 [CI](https://github.com/jung-geun/SIFT/actions/runs/41295869837)·보안 검사를 통과해 소스를 병합했고, 운영 CloudKit에는 기존 모든 형식을 유지한 채 암호화된 `CD_CloudDataRevision` 형식만 추가 배포했습니다. 데이터·스키마 초기화는 하지 않았습니다.

원본 프로젝트의 최종 전체 단위 테스트는 **iOS 시뮬레이터 1,576개·Mac Catalyst 1,574개가 통과**했고 실패·예상 실패·건너뜀·구조화된 런타임 경고는 모두 0입니다. 두 아카이브의 오류·분석기 경고는 0이며 iOS 컴파일러 경고는 0, Mac은 회의 감지 코드의 Swift 동시성 경고 4개가 남습니다. iOS 업로드에는 GoogleMobileAds·UserMessagingPlatform의 제3자 dSYM 누락 경고가 있습니다. 테스트 통과는 실제 다자 통화 수집·모든 외부 서비스·심사 승인 보증이 아닙니다. 상세 근거와 이전 단계의 한계는 [UI 테스트 계획](https://github.com/jung-geun/SIFT/blob/main/ios/UI_TEST_PLAN.md)에 구분했습니다.

- 회의 요약에서 할 일로 분류된 문장을 그대로 등록 대기열에 추가합니다. 별도 후보 목록과 업무명 재요약을 제거하고 원문 근거·중복 방지를 유지합니다.
- 다시 요약에서 Apple Intelligence 또는 별도로 연결·동의한 GPT 모델을 선택합니다. 계정·지역·소스·취소 검증과 이전 결과 보존을 유지하며 AI 결과의 누락 가능성은 남습니다.
- 확인 후 회의 전체와 모든 소속 음성 소스·전사·요약·원음을 삭제하고 이미 등록한 할 일은 유지합니다. 개별 소스 원본 ZIP/WAV 또는 모든 소스 원본 ZIP을 실제 시스템 저장 창으로 저장합니다.
- 회의 복구 시 부모 표시가 같아도 자식·멤버십 변경을 저장한 후 저널을 정리하고, 저장 실패 시 기존 전사·원음·복구 기록을 보존합니다. 요약 출력 설정만 변경했을 때 기존 요약을 지우지 않으며, 새 형식의 지문으로 현재 원문 근거가 그대로임을 확인하면 그 요약에서 할 일 등록도 유지합니다. 실제 근거 변경은 요약 근거를 무효화하고, 검증할 수 없는 구버전 요약은 표시만 유지하며 등록을 차단합니다.
- 같은 시각의 편집된 전사 행은 실제 표시 순서에 맞게 화자 제목을 이어 표시합니다. 원문 화자 배정은 바꾸지 않으며 수동 경계·소스 변경·실제 겹침은 유지합니다.
- Mac 감지 앱 출력은 해당 앱 번들 내부 실행 파일과 정확한 실행 인스턴스의 부모 프로세스 관계가 검증된 오디오 프로세스만 수집합니다. 승인한 스냅샷의 프로세스 추가·제거·교체·부모 변경 시 중단하고 다시 선택해야 하며 자동으로 범위를 넓히지 않습니다. 이 소유 관계를 증명할 수 없는 공유 WebKit helper를 쓰는 **Safari 앱별 수집은 지원하지 않습니다.** 별도 출력 장치 전체 수집으로 자동 전환하지 않습니다.
- 광고 동의 설정 진입점·Mac 회의 활동 감지·명시적 출력 장치 수집·계정 응답·사용량·기존 클라우드 삭제 기록의 호환성을 개선했습니다. 실광고 제공·Google 양식 게시·기존 툴바 충돌 해결·물리 다자 통화 수집을 보장하지 않습니다. iCloud를 쓰는 기기는 같은 최신 버전으로 업데이트하세요.

개정 [개인정보처리방침](https://sift.pieroot.xyz/privacy-policy)은 **2026-11-01 공고·2026-11-09 시행 예정**으로 실제 공개 URL에서 확인했습니다. [Pages 배포](https://github.com/jung-geun/SIFT/actions/runs/41297008513)가 성공했고 최소 7일 고지 기간보다 이르게 앱이 공개되지 않도록 예약했습니다. 회의 전사문 외부 요청은 기존 동의나 계속 사용이 아니라 각 기기의 별도 동의와 직접 실행을 요구합니다.


<a id="version-1-0-13-12"></a>
## 1.0.13 (12) — 심사 접수·공개 전

**2026-10-30 17:45 KST 확인 기준**, iOS·universal Mac `1.0.13 (12)`의 업로드 처리가 모두 `VALID`이며 두 플랫폼 모두 **Waiting for Review**로 심사 접수됐습니다. **승인 후 자동 출시**하며 아직 패치 공개 완료는 아닙니다. [PR33](https://github.com/jung-geun/SIFT/pull/33)의 [수정 후 CI](https://github.com/jung-geun/SIFT/actions/runs/41025004282)·보안 검사를 통과했습니다. 기존 Mac `1.0.12 (11)`은 `Ready for Sale`로 확인했고, iOS의 대기 제출을 이번 패치로 교체했습니다. 현재 iOS 공개 조회는 `1.0.11`입니다.

- 자동 동기화의 보호된 연결 정보 확인은 인증 창 없이 수행하고, 별도 승인 작업에서 인증 목적·현재 그룹·취소·대기 상태를 안내합니다. 이미 검증한 키체인 기록을 재사용하면서 기존 보호 수준을 유지합니다.
- 작은 동기화 변경을 제한된 묶음으로 저장해 디스크 쓰기와 CloudKit 내보내기 요청을 줄였습니다. 원문·리비전 ID·중간 실패 후 재시작과 취소 처리는 보존합니다.
- 회의 시스템 오디오 오류의 실패 단계·SDK 코드를 유지하고 Mac 캡처 권한을 안내합니다. 진단 수집을 나중에 허용해도 오류를 잃지 않습니다.
- 오류 보고 작성 취소·전송 실패 후 진단 검토·초안·제출 ID를 유지하고, 실제 진단 접수 성공일 때만 전달 완료로 처리합니다. 관련 안내는 8개 앱 언어에 반영했습니다.

## 1.0.12 (11) — 이전 심사 제출 기록

**2026-10-30 06:51 KST 확인 기준**, iOS·universal Mac `1.0.12 (11)`의 업로드 처리가 모두 `VALID`이며 두 플랫폼 모두 **Waiting for Review**로 심사 접수됐습니다. **승인 후 자동 출시**하며 아직 공개된 버전은 `1.0.11`입니다. [PR32](https://github.com/jung-geun/SIFT/pull/32)의 [최종 CI](https://github.com/jung-geun/SIFT/actions/runs/40959391692)·보안 검사를 통과하고 main에 반영했습니다. 앱·확장의 실제 버전, Mac 양쪽 아키텍처·네이티브 지원 번들, 배포 서명·프로덕션 권한과 원음 보존·재생을 확인했습니다. 아카이브·업로드·심사 접수는 승인·공개 완료와 구분합니다.

- 모바일 캘린더의 월 표시 밀도·연도·일·여러 날 보기, 연속 스크롤·핀치·오늘 이동과 좁은 iPad 화면을 개선했습니다. Mac에서는 빈 시간 클릭·범위 드래그·일정 가장자리 크기 조절·우클릭 편집을 지원합니다.
- 일정 직접 수정·삭제 시 기존 할 일 연결·완료 기록·반복 일정·시간대 경계를 보존하고, 삭제한 일정이 자동 등록으로 다시 생기지 않도록 보완했습니다.
- 실제 입력 파형, iPhone·iPad의 Live Activity와 Mac 메뉴 막대 녹음 표시를 추가했습니다. 실시간 전사는 Apple 기본 모델을 사용하며 선택형 Whisper는 종료 후 처리에만 사용합니다. 전사 실패와 원음 저장 실패를 구분합니다.
- Mac 오디오 가져오기에 선택 파일 읽기 권한과 네이티브 열기 패널을 적용했습니다. 원본 변경 없이 로컬 저장·재생하며 iPhone·iPad 파일 선택 경로를 유지합니다.
- 설정을 AI·회의·할 일·루틴의 역할에 맞게 정리했습니다. Apple Intelligence의 실제 지원·준비 상태와 로컬 모델 사용 동의를 구분하며, 외부 분석은 연결된 계정·지원 지역·개별 공유 동의가 있을 때만 실행합니다.
- 메일 동기화 성공 팝업을 없애고 기기에서 아직 열지 않은 새 메일에 파란 점을 표시합니다. 할 일 검색·필터를 고정하고 Duo 초안 유지, 빈 공간 두 번 클릭·터치 생성, Mac 버튼·편집·명암 대비를 개선했습니다.

다음 항목별 기록은 개발·검증 당시의 범위를 보존합니다. 새 버전의 실제 스토어 상태는 별도 배포 확인 기록을 기준으로 합니다.

## 개발 소스 — 회의 전체 삭제·소스별 음성 다운로드 (미배포)

- 회의 목록의 각 행에 별도 작업 메뉴를 추가했습니다. **회의 기록 삭제**는 확인 후 회의 전체와 소속 음성 소스·전사·요약·원음/복구 자료를 삭제하며, 개별 트랙 삭제가 아닙니다. 이미 등록한 할 일은 남습니다. 기존 삭제의 진행 작업 취소·저장 실패 시 원음 보존·늦은 동기화 복구 차단을 재사용합니다.
- 목록·그룹 상세·회의 설정에서 개별 소스의 원본 ZIP/WAV와 모든 소스의 원본 ZIP을 선택할 수 있습니다. 전체 다운로드는 읽을 수 있는 일부 소스만 성공으로 돌려주지 않으며 소스별 파일·고유 이름공간·시작 오프셋을 보존합니다.
- 공유 메뉴만 여는 대신 실제 저장 위치를 고릅니다. iPhone·iPad는 Files, Mac은 기존 네이티브 파일 패널 브리지를 통한 ‘다른 이름으로 저장’을 사용합니다. Mac 권한은 사용자 선택 파일 읽기·쓰기로 제한하며 기존 가져오기 원본은 수정하지 않습니다.


## 개발 소스 — Xcode 동시성·패키지 경고 정리 (미배포)

- 출력 오디오의 PCM 실패·네이티브 실패·시작 완료 콜백에서 MainActor 작업마다 독립적인 약한 `self` 캡처를 사용합니다. 동의·세대 검사·취소·늦은 콜백 차단·오디오 소유권은 유지하며 동시성 검사를 끄지 않았습니다.
- vendored `mlx-swift-lm`이 Xcode와 동일한 형제 로컬 `mlx-swift` 패키지를 참조하도록 통일하고, 실제로 존재하지 않는 중첩 `mlx/build` 제외 항목을 제거했습니다. 모델 알고리즘·배포 대상·외부 의존성 버전은 바꾸지 않았습니다.


## 개발 소스 — 광고 동의 양식 진입점 (미배포)

- iPhone·iPad 설정에 **광고 동의 및 개인정보**를 항상 표시합니다. 버튼을 누르면 Google UMP 상태를 다시 확인하고 필요한 공식 동의 양식 또는 개인정보 옵션을 엽니다. 동의가 필요 없으면 그 결과를 안내하며, 네트워크·양식 구성 오류는 동의 완료로 처리하지 않습니다.
- 양식을 확인·변경하는 동안 기존 광고를 숨기고, Google의 광고 요청 허용 상태를 다시 적용합니다. 자체 동의 체크박스·강제 동의·동의 상태 초기화는 추가하지 않았습니다.
- 운영 양식은 AdMob **Privacy & messaging**에서 해당 앱에 연결해 게시해야 합니다. 앱 코드 추가만으로 Google 양식 게시나 광고 게재 승인이 완료되지 않습니다. Mac 앱의 광고 제외는 유지합니다.


## 개발 소스 — iCloud 삭제 상태 충돌·동기화 복구 (미배포)

- 동기화 리비전의 저장 속성 `isDeleted`가 SwiftData의 객체 삭제 상태와 충돌해, 삭제 기록이 본문 없는 일반 항목으로 검증되고 전체 반영이 중단되는 문제를 수정했습니다. CloudKit은 기존 필드의 이름 변경을 허용하지 않으므로 기존 wire 필드는 유지하고 별도 `isTombstone` 속성을 추가했습니다.
- 이미 영향을 받은 기록은 저장된 삭제 표식 또는 리비전 ID·논리 시계·설치 ID가 정확히 일치하는 영속 저널의 삭제 의도와 실제 빈 본문을 함께 확인한 경우에만 복구합니다. 원본 본문이나 다른 기기의 데이터를 삭제·초기화하지 않으며, 이후의 새 변경 대기열도 보존합니다. 근거 없는 빈 본문은 삭제로 추측하지 않습니다.
- 일부 파일을 읽지 못해도 의존 관계가 없는 다른 항목은 계속 처리하지만, 전체 완료로 표시하지 않습니다. 계정·저장소 준비, 데이터 검증·복원, 저장소별 CloudKit 전송 오류를 구분하고 해당 단계가 실제 복구됐을 때만 해제합니다. 설정에는 비공개 내용을 제외한 실패 단계·오류 코드를 표시합니다.

## 개발 소스 — 요약 문장 안에서 할 일 추가 (미배포)

## 개발 소스 — 전체 회의 맥락 기반 할 일 추출 (미출시)
> 아래는 이전 요청·수락 기반 후보 구현의 검증 기록입니다. 현재 작업 흐름은 위의 **요약 문장 안에서 할 일 추가**로 대체했으며, 이전 후보 카드·업무명 생성의 수치와 제한은 새 분류 방식의 성능 결과가 아닙니다.


- 전사문에 `해야`·`보내` 같은 단어가 있다는 이유로 문장을 그대로 태스크 후보로 만들던 규칙을 제거했습니다.
- Apple Foundation Models의 구조화(스키마) 생성은 약 47분 한국어 회의에서 `actions` 항목을 만들기 전에 출력이 끊겨 분석 전체가 원문 발췌로 되돌아갔습니다. 회의 요약은 이제 화자별 문단으로 묶은 대화 조각을 일반 문장으로 정리한 뒤 각 문장을 전사 구간에 연결합니다. 여러 절로 이루어진 문장은 절의 3분의 2 이상이 전사에서 확인될 때만 남기고, 한 절짜리 문장은 낮은 기준으로 대조합니다. 근거 표시는 출처가 있다는 뜻이며 내용이 정확하다는 보증이 아닙니다.
- 할 일 후보는 모델의 추측이 아니라 전사문에서 **한 사람이 부탁하고 다른 사람이 짧은 수락 표현으로 받아들인 대목**을 찾아 만듭니다. 모델은 그 대목이 구체적인 일인지와 일의 이름만 판단하며, 근거는 그 요청·수락 구간입니다. 아무도 받아들이지 않은 요청, 설명 뒤의 단순한 응답, 제목이 아닌 답변은 후보가 되지 않습니다.
- 화자 정보가 없는 전사(화자 구분 끄기, 그룹 요약)는 일정 길이로 나눠 요약하지만 요청과 수락을 구분할 수 없어 할 일 후보를 만들지 못합니다. 한 구간이 아주 긴 가져온 전사도 나눠 요약하며, 겹친 발화가 한 덩어리에 들어가지 않으면 이전 화자로 단정하지 않고 화자 미확정으로 둡니다.
- 실제 47분 회의에서 확인된 한계: 할 일 이름이 대상을 완전히 풀지 못하는 경우("안을 준비함")가 있고, 명시적 수락 표현이 없는 요청과 스스로 한 약속(예: 대체 PC 조립 후 연락)은 찾지 못합니다. 요약에는 음성 인식 오류(예: GPU 모니터링 도구 이름)가 사실처럼 남을 수 있고, 근거가 약한 문장을 걸러내면서 일부 실제 내용(성능 이상치, CPU 사용 비율)이 빠졌습니다. 이 전사 하나로만 검증했으며 정확도나 재현율 보증이 아닙니다. 등록은 계속 사용자 확인 후에만 이루어지고 기존 저장 결과는 다시 처리하기 전까지 바뀌지 않습니다.
- 최종 실제 모델 재실행은 약 102초·14회 호출로 요약 15문장과 후보 카드 3개를 만들었고 모든 인용 ID가 입력에 존재했습니다. 기준 업무 5개와 비교하면 설명 자료와 운영 정책 초안 요청에 최대 2개의 부분 일치가 있고, 나머지 3개는 누락됐습니다. 별도 후보인 "가상화 수행"은 일반 논의를 독립 업무로 만들지 말라는 기준을 위반한 오탐 1개입니다. 모호한 "안 준비"도 근거 맥락에 의존한 부분 일치일 뿐이며, 후보 카드 수나 인용 유무를 정확도·업무 재현율로 해석하지 않습니다.
- Mac 검수 빌드를 막던 출력 오디오 브리징 소스의 타깃 등록 누락과 `CoreAudio` import 누락을 수정했습니다. 공유 브리지는 앱·네이티브 번들 양쪽에, 출력 오디오·회의 감지 구현은 네이티브 번들에 등록했습니다. 실제 `todo-QA` Mac Catalyst 빌드·서명 검증과 번들 로드·프로토콜 캐스트·출력 장치 열거를 확인했으며, 이 검증에서 녹음을 시작하지 않았습니다.

- Mac 연속 캘린더에서 재사용되는 주 셀의 표시 뷰를 셀 수명 동안 유지하고, 스크롤·창 크기 변경 때 해당 셀의 실제 영역에 맞춰 배치하도록 보완했습니다. 주 전체가 선택·포커스되는 테두리를 없애고 날짜·일정 버튼의 동작은 유지합니다.
- GitHub CI의 출력 파이프가 `xcodebuild` 실패를 성공으로 가리던 경로를 제거하고, 최신 Xcode 러너에서 단위 테스트 결과 번들을 보존하도록 바꿨습니다. 이전 녹색 상태는 실제 빌드·테스트 통과의 근거로 사용하지 않습니다.

한국어·영어 iPhone/iPad의 실제 QA 화면 16장을 다시 촬영해 소개 이미지 20장·홈페이지 WebP 4장과 ZIP을 모두 교체했습니다. 소개 화면은 합성 예시 데이터와 내부 광고 없는 모드를 사용하며, 공개 광고 제거 기능이나 App Store 이미지 교체 완료를 뜻하지 않습니다. [PR 28](https://github.com/jung-geun/SIFT/pull/28)의 [main CI](https://github.com/jung-geun/SIFT/actions/runs/39651522003)·[Pages 배포](https://github.com/jung-geun/SIFT/actions/runs/39651522293)가 성공했고, 공개 이미지의 파일 해시 일치와 갤러리 동작을 확인했습니다.

## 1.0.11 (9) — 이전 심사 제출 기록

**2026-10-21 당시 확인 기준**으로 공개 앱은 **1.0.10**, 심사 제출 버전은 **1.0.11 (9)**였습니다. iOS/iPadOS는 스토어 문구·이미지를 보정해 **15:52 KST 재접수·Waiting for Review**, macOS는 **In Review**였습니다. 이 요청들은 10월 22일 빌드 10 재제출로 대체됐습니다. 아래는 빌드 9부터 포함된 기능과 사용 경로입니다.

SIFT의 중심은 **할 일 작성·분류·완료**입니다. 메일·캘린더·회의·AI는 선택 기능이며 연결하지 않아도 할 일을 관리할 수 있습니다. 아래 경로는 한국어 UI 기준입니다. iPhone/iPad는 **할 일 → 더 보기 → 설정**, Mac은 **SIFT → 설정…** 또는 **⌘,**에서 설정을 엽니다.

| 변경 | 사용 방법 |
| --- | --- |
| **할 일 중심 설정** | **설정 → 할 일**에서 마감 알림 권한·우선순위 정렬용 AI·규칙을 관리합니다. 준비된 AI만 선택할 수 있고 계정 연결·전송 동의는 별도입니다. Mac 보드의 **⋯ 또는 우클릭 → 세부 정보**에서 제목·메모를 편집합니다. |
| **캘린더 분석 출처 직접 선택** | **설정 → 캘린더 설정 → 할 일 분석 캘린더**에서 가져올 캘린더를 고릅니다. 기본 선택은 없으며 표시용·등록 대상과 독립적입니다. 공휴일이나 공용 장비 일정은 선택하지 않을 수 있습니다. 선택 해제는 새 가져오기와 미승인 제안 갱신을 멈추며 승인한 할 일은 지우지 않습니다. 캘린더 권한도 이 설정에서 요청합니다. |
| **AI 계정과 모델 설치 분리** | **설정 → AI**에서 지원 지역의 계정·공유 동의를, **설정 → 베타 기능**에서 로컬 모델의 설치·취소·삭제를 관리합니다. 화면 진입만으로 다운로드하지 않습니다. 중국 본토 App Store·국가 미확인 상태에서는 선택형 외부 분석을 제공하지 않으며 기본 할 일·로컬 기능은 유지합니다. |
| **선택형 iCloud 전체 저장** | **설정 → iCloud 동기화 → 앱 데이터 전체를 iCloud에 저장**에서 메일·회의·루틴·단어장·설정의 확대 범위를 확인하고 켭니다. 연결 정보는 iCloud 키체인을 사용합니다. 건강정보·OS 권한·다운로드 모델 파일은 제외합니다. 전송 대기와 Apple이 확인한 완료를 구분합니다. |
| **회의 재생·마지막 언어 기억** | 저장한 회의의 **전체 음성·대화 타임라인**에서 소스의 공통 시각에 맞춰 듣고 읽습니다. 원본 소스는 유지합니다. 녹음·가져오기·상세에서 고른 음성·요약 언어를 각각 기억하며 이력이 없으면 지원되는 시스템 언어를 따릅니다. 자동 감지는 설치·활성화한 Whisper가 필요합니다. |
| **선택형 루틴·건강 기록** | **설정 → 루틴 학습·추천**에서 완료한 수동 할 일의 근거를 검토하고 일정을 승인합니다. 지원되는 iOS 기기의 **건강·운동 기록**은 별도 읽기 권한·출처 승인·자동 생성 동의를 요구합니다. 완료 체크는 실제 활동의 증거가 아니며 처방·용량 조언을 하지 않습니다. |
| **로그인 없는 의견 접수** | **설정 → 앱 정보 → 의견 보내기**에서 내용·환경 정보·선택한 진단을 검토하고 동의한 뒤 전송합니다. 이메일 연결이나 계정은 필요하지 않습니다. 실제 접수번호를 받은 경우에만 성공으로 안내합니다. |

### 화면과 안정성

- 재생 설정·파형·할 일 보드의 여백과 밝음/어두움 표시를 정리하고, 튜토리얼을 실제 입력란·설정 항목 옆에 배치했습니다. Mac 월간 캘린더는 출처 사이드바·미니 달력·월 격자를 정리하고 일정 조회 중 화면 이동 지연을 줄였습니다.
- Mac의 비활성 할 일·메일 도구 모음 충돌, 모델 미사용 상태의 불필요한 Metal 초기화, 짧은 회의 FLAC 저장·재생 수명 문제를 수정했습니다. 앱과 로컬 MLX의 컴파일 진단을 정리했습니다.
- iOS/iPadOS는 UMP가 허용할 때 하단 **320×50 배너 하나**를 사용합니다. 온보딩·튜토리얼·키보드·비활성 상태 등에서는 공간을 접고 전면·앱 시작·보상형 광고는 없습니다. Mac에는 광고 SDK를 연결하지 않습니다. [개정 개인정보처리방침](privacy-policy.html)은 **10월 27일 시행 예정**입니다.
- **등록 대기 항목은 일괄 AI 정렬·알림·자동 캘린더 등록에서 제외**하며 자동 등록에는 별도 동의가 필요합니다. iCloud 실계정 다기기 전파, 모든 언어의 AI 정확도, 실제 다중 소스 통화·물리 기기 성능까지 보증하는 변경은 아닙니다.

현재 소개 페이지의 예시 화면은 **1.0.11 (10) 소스의 QA 앱과 합성 데이터**로 다시 촬영했습니다. App Store 이미지 업로드·심사 승인·공개 출시와 구분합니다. 실행 범위와 원본 근거는 [dev의 UI 검증 기록](https://github.com/jung-geun/SIFT/blob/dev/ios/UI_TEST_PLAN.md)에 남깁니다. iOS/iPadOS 26 이상·macOS 26 이상용 제출이며 Android 신규 배포를 뜻하지 않습니다.

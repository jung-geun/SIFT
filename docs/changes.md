# 변경사항

<a id="version-1-0-17"></a>
## 1.0.17

### 할 일·메모·연결·동기화

- 할 일 목록과 보드에서 태그를 골라 해당 태그의 할 일만 모아볼 수 있습니다.
- 메모에 적은 내용에서 온디바이스 AI가 할 일 후보를 추천합니다. 선택한 후보만 등록되며, 이미 있는 할 일과 같은 제목은 중복으로 표시합니다.
- Mac 설정의 MCP 연결을 켜면 이 기기 안에서만 로컬 AI 도구가 할 일을 조회하고 추가·수정·완료할 수 있습니다. 기본값은 꺼짐이며 토큰으로 인증합니다.
- iCloud로 보내는 데이터를 줄였습니다. 메일 HTML 본문은 각 기기에만 보관하고, 120일이 지난 행동·감사 기록은 자동으로 정리합니다.
- 수동 AI 정리가 응답하지 않으면 10분 뒤 오류로 끝나며, 메일 분석 중에는 정리 배너를 띄우지 않습니다.

<a id="version-1-0-16"></a>
## 1.0.16

### 광고 제거

- 일반 화면의 광고와 광고 동의 항목을 없앴습니다. 모든 앱 기능을 인앱 결제 없이 무료로 사용할 수 있습니다.

### 동기화·메일·우선순위

- 동기화, 메일 확인, 캘린더·회의 처리, 우선순위 정리가 서로를 기다리지 않고 따로 진행됩니다.
- 변경된 항목만 iCloud와 동기화하고, 새 할 일을 추가했을 때만 우선순위를 정리합니다. 기존 할 일을 완료하거나 수정해도 전체 우선순위를 다시 계산하지 않습니다.
- 앱을 사용하는 동안 약 45초마다 새 메일과 본문을 확인하고, 각 기기가 새 메일의 처리 항목을 분석합니다. 분석이 실패하면 간격을 늘려 다시 시도합니다.
- "로컬 데이터 복원 완료" 안내가 반복해서 나타나던 문제와, 메일 분석 중에도 "AI 우선순위 정리 중…"으로 표시되던 문제를 고쳤습니다.

<a id="version-1-0-15"></a>
## 1.0.15

### 할 일·메일 목록

- Mac 할 일·메일 목록의 상시 꺾쇠를 없애고 마우스를 올린 행 오른쪽에 더보기 메뉴를 표시합니다. 행 클릭은 상세를 열고, 더보기 클릭·우클릭은 옵션만 엽니다.
- iPhone·iPad 할 일 상세의 완료·삭제 버튼을 큰 채움형 버튼 대신 기본 폼 행으로 정리하고, 삭제는 표준 삭제 색상으로 구분합니다. 태그 추가 버튼도 간결하게 조정했습니다.

### 캘린더

- iPhone·iPad 캘린더의 왼쪽 상단에 연도와 월을 함께 표시하고, 스크롤한 달에 맞춰 갱신합니다. 연말·연초에도 해당 연도와 월을 확인할 수 있습니다.
- 달력 안의 월 제목에도 연도를 표시해 다른 해의 같은 달을 구분할 수 있도록 개선했습니다.

- iPhone과 작은 iPad의 주 보기는 화면 폭에 맞춰 한 번에 2~3일을 표시하며, 넓은 iPad 화면에서는 7일을 함께 볼 수 있습니다.
- 날짜를 가로로 부드럽게 스크롤할 수 있도록 바꾸고, 캘린더 안에서 오른쪽으로 쓸 때 이전 화면으로 돌아가던 동작을 막았습니다. 뒤로 가기 버튼은 그대로 사용할 수 있습니다.
- 종일·하루 이상 이어지는 일정을 날짜별로 반복하지 않고 기간을 잇는 하나의 막대로 표시합니다. 날짜 머리글·시간표·기간 막대가 함께 스크롤되며 시간 눈금은 고정합니다. 하루 미만의 시간 지정 일정은 자정을 넘더라도 날짜별 시간표에 표시합니다.

### 메일

- 전체 본문 분석의 **확인/처리 필요** 항목에서만 할 일을 제안합니다. 항목이 없으면 메일 제목·요약을 할 일로 바꾸지 않으며, 직접 입력한 할 일은 따로 저장할 수 있습니다.
- 한 메일의 여러 처리 항목을 각각 저장하고, 제목을 수정한 뒤에도 같은 항목의 중복 등록을 막습니다. 직접 추가한 캘린더 일정도 할 일별로 구분하며 원본 메일 참조는 유지합니다.
- 끊어진 IMAP 연결을 다음 조회에서 다시 연결하고, 읽음 처리 실패가 본문 수신까지 막지 않도록 개선했습니다. 다른 계정의 연결에서 읽음·휴지통 작업을 실행하지 않습니다.
- 앱이 활성화될 때와 주기적으로 목록·전체 본문을 기기에 저장합니다. AI 분석을 꺼도 캐시는 유지하며, 백그라운드 수집은 허용한 계정에만 적용되고 실행 시각은 iOS가 결정합니다.
- 메일 요약 카드의 위·아래 여백을 맞추고, 처리 항목 선택 화면에서 긴 항목 이름을 읽을 수 있도록 개선했습니다.
- 큰 첨부파일은 제외하고 완전한 텍스트 본문과 표시용 HTML을 받아 메일 끝의 처리 항목을 보존합니다. 기기의 연결 실패로 동기화된 유효한 요약을 지우지 않으며, 할 일 삭제 실행 취소 후에도 메일 처리 항목의 출처와 중복 방지를 유지합니다.

### 설정·동기화

- **동기화 충돌** 화면에서 항목별 버전과 서로 다른 내용을 비교하고, 사용할 버전을 직접 선택해 적용할 수 있습니다. 비교 중 변경된 항목은 다시 확인하도록 하며, 충돌 없는 다른 항목의 동기화는 계속합니다.
- 충돌 해결 전에 원본 버전을 기기에 보관하고, **보관한 버전**에서 다시 비교·복원할 수 있습니다. 직접 선택한 버전으로 같은 항목의 중복을 하나로 합칩니다.
- 광고 개인정보 양식의 앱 구성 오류, 네트워크 오류·시간 초과, 양식 제공 실패를 구분해 해결 방법을 안내합니다. Google 측 설정 문제를 단순 재시도로 해결할 수 있는 오류처럼 표시하지 않습니다.
- 이전 버전 할 일의 iCloud 복원 호환성을 개선했습니다. 새 메일 처리 항목으로 만든 할 일은 1.0.14에서 읽지 못해 동기화가 중단될 수 있으므로, 같은 iCloud 계정의 iPhone·iPad·Mac을 모두 이번 버전으로 업데이트하세요.

<a id="version-1-0-14-13"></a>
## 1.0.14 (13)

### 회의

- 요약에서 할 일로 분류된 문장 옆에 **할 일 추가** 버튼을 제공합니다. 별도 후보 목록과 업무명 재요약 없이 확인한 문장 그대로 등록 대기열에 추가하며, 원문 근거 확인과 중복 방지를 유지합니다.
- **다시 요약**에서 Apple Intelligence, GPT-6.1 Sol, GPT-6 Luna를 직접 선택할 수 있습니다. GPT는 연결된 계정과 기기별 회의 전송 동의가 있을 때만 사용하며, 오류·취소 시 이전 결과를 보존합니다.
- 사용자 지정 요약 지침이 비어 있어도 형식 선택과 지침 편집을 할 수 있도록 수정했습니다.
- Apple Intelligence의 긴 회의 처리를 단계별로 나누고, 출력 언어 지정과 원문 근거 검증을 개선했습니다.
- 같은 화자의 연속 전사와 앞뒤 화자가 같은 미검출 구간을 문단으로 묶어 표시합니다. 수동 구분·소스 변경·실제 겹친 발화는 유지하며 원본 화자 배정을 바꾸지 않습니다.
- 요약의 여러 근거 버튼을 위치 링크와 근거 메뉴로 정리했습니다.
- 확인 후 **회의 전체와 소속 음성 소스·전사·요약·원음**을 삭제할 수 있습니다. 이미 등록한 할 일과 외부에 저장한 파일은 유지합니다.
- 개별 소스의 원본 ZIP/WAV 또는 모든 소스의 원본 ZIP을 iPhone·iPad의 Files와 Mac의 저장 창에서 저장할 수 있습니다. 여러 소스의 파일과 시작 오프셋을 구분해 보존합니다.
- Mac 오디오 가져오기에 Finder 파일 드래그 앤 드롭과 붙여넣기 버튼·⌘V를 추가했습니다. 원본 파일은 수정하지 않습니다.
- 회의 복구 시 자식·멤버십 변경을 저장한 뒤 복구 기록을 정리하도록 수정했습니다. 저장 실패 시 기존 전사·원음·복구 기록을 보존합니다.
- 요약 출력 설정만 바꿨을 때 기존 요약을 유지합니다. 원문 근거가 그대로임을 확인할 수 있는 요약에서는 할 일 등록도 유지하며, 실제 근거가 바뀌거나 검증할 수 없으면 등록을 차단합니다.
- Mac 회의 활동 감지와 앱별 출력 수집을 개선했습니다. 선택한 앱의 실행 파일·프로세스 소유 관계를 확인하고, 수집 대상이 바뀌면 중단해 다시 선택하도록 합니다. 공유 WebKit helper를 사용하는 Safari 앱별 수집은 지원하지 않습니다.

### 설정·계정·동기화

- AI 계정 화면의 확인할 수 없는 요금제 등급과 불필요한 모델 목록을 제거하고, 연결 상태·연결 테스트·전송 동의·사용량을 중심으로 정리했습니다.
- ChatGPT JSON 요청 형식과 완료 응답 처리를 수정했습니다. 이 기기에서 확인한 계정별 입력·출력·캐시된 입력 토큰과 응답 수를 표시하며, 계정 전체 사용량이나 잔여 한도로 해석하지 않습니다.
- 변경 없는 계정 연결 기록이 전체 동기화를 반복 예약하던 문제를 수정했습니다.
- iCloud 삭제 기록의 호환성과 복구를 개선했습니다. 내용이 다른 중복 식별자는 임의로 덮어쓰지 않고 해당 항목만 보류해 다른 변경의 동기화를 이어갑니다.
- 회의·AI·베타 기능 설정의 중복 설명과 빈 항목을 줄이고, 작은 화면·큰 글자에서 모델 행과 선택값이 잘리지 않도록 개선했습니다.
- iPad 페르소나 재설정·생성 버튼의 터치 영역을 넓혔습니다.
- iPhone·iPad 설정에 **광고 동의 및 개인정보** 진입점을 추가했습니다. Google의 동의 상태를 다시 확인하며 양식 오류를 동의 완료로 처리하지 않습니다. Mac의 광고 제외는 유지합니다.

<a id="version-1-0-13-12"></a>
## 1.0.13 (12)

- 자동 동기화의 보호된 연결 정보 확인은 인증 창 없이 수행하고, 별도 승인 작업에서 인증 목적·현재 그룹·취소·대기 상태를 안내합니다.
- 작은 동기화 변경을 제한된 묶음으로 저장해 디스크 쓰기와 CloudKit 내보내기 요청을 줄였습니다. 원문·리비전 ID·중간 실패 후 재시작과 취소 처리는 보존합니다.
- 회의 시스템 오디오 오류의 실패 단계·SDK 코드를 유지하고 Mac 캡처 권한을 안내합니다. 진단 수집을 나중에 허용해도 오류를 잃지 않습니다.
- 오류 보고 작성 취소·전송 실패 후 진단 검토·초안·제출 ID를 유지하고, 실제 진단 접수 성공일 때만 전달 완료로 처리합니다.

<a id="version-1-0-12-11"></a>
## 1.0.12 (11)

- 모바일 캘린더의 월 표시 밀도·연도·일·여러 날 보기, 연속 스크롤·핀치·오늘 이동과 좁은 iPad 화면을 개선했습니다.
- Mac 캘린더에서 빈 시간 클릭·드래그로 일정을 만들고, 일정 가장자리 드래그로 시간을 조정하며, 우클릭으로 편집·삭제할 수 있습니다.
- 일정 직접 수정·삭제 시 기존 할 일 연결·완료 기록·반복 일정·시간대 경계를 보존하고, 삭제한 일정이 자동 등록으로 다시 생기지 않도록 보완했습니다.
- 실제 입력 파형, iPhone·iPad의 Live Activity와 Mac 메뉴 막대 녹음 표시를 추가했습니다. 실시간 전사는 Apple 기본 모델을 사용하며 선택형 Whisper는 종료 후 처리에만 사용합니다.
- 녹음 중 전사 실패와 원음 저장 실패를 구분하고, Apple 전사의 실제 입력 포맷 지원 여부를 확인하도록 개선했습니다.
- Mac 오디오 가져오기에 사용자 선택 파일 읽기 권한과 네이티브 열기 패널을 적용했습니다. 원본 변경 없이 로컬 저장·재생합니다.
- 설정을 AI·회의·할 일·루틴의 역할에 맞게 정리했습니다. Apple Intelligence의 실제 준비 상태와 대체 로컬 모델 사용 동의를 구분하며, 외부 분석은 연결·지원 지역·개별 공유 동의가 있을 때만 실행합니다.
- 메일 동기화 성공 팝업을 제거하고, 아직 열지 않은 새 메일에 파란 점을 표시합니다.
- 할 일 검색·필터를 고정하고, 빈 공간 두 번 클릭·터치로 할 일을 만들 수 있도록 했습니다.
- Duo 화면 전환 시 새 할 일 초안을 유지하고, 작은 화면에서 저장 버튼이 입력 영역을 가리지 않도록 개선했습니다.
- Mac 할 일 버튼·편집·명암 대비와 캘린더 일정 조회·스크롤을 개선했습니다.

<a id="version-1-0-11-10"></a>
## 1.0.11 (10)

- iPhone·iPad 할 일 배너를 화면 하단에서 카테고리 아래의 고정 영역으로 옮겼습니다.
- Mac 언어 검색을 선택 화면 상단에 배치하고, 이전 화면으로 돌아가면 검색창이 남지 않도록 수정했습니다.
- Mac 캘린더 사이드바 버튼을 상단 도구 모음으로 옮기고, 이전·다음 달의 주가 중복 없이 이어지도록 수정했습니다.
- 연결된 할 일 때문에 일정이 사라지던 문제와 하루 일정 상단의 과도한 여백을 수정했습니다.
- 할 일 드래그 미리보기에 메타데이터를 포함하고, 모델 설치·취소·삭제 컨트롤을 통일했습니다.
- 회의 대화 타임라인을 화자·시간·본문 중심으로 정리하고, 같은 화자의 반복 제목과 여백을 줄였습니다.
- 하루 일정의 시간 눈금과 배치 오차를 수정하고, 큰 화면의 할 일 편집기와 Gmail·Outlook 연결 행의 클릭 영역을 개선했습니다.
- Mac 연속 캘린더의 스크롤·창 크기 변경 대응을 개선하고 불필요한 주 선택 테두리를 제거했습니다.

## 1.0.11 (9)

- 할 일 설정에서 마감 알림·우선순위 정렬용 AI·규칙을 관리하고, Mac 보드에서 제목·메모를 편집할 수 있도록 정리했습니다.
- 할 일 분석에 사용할 캘린더를 직접 선택할 수 있습니다. 선택 해제 시 새 가져오기와 미승인 제안 갱신만 멈추며 승인한 할 일은 유지합니다.
- AI 계정 연결·전송 동의와 로컬 모델 설치·취소·삭제를 분리했습니다. 화면 진입만으로 모델을 다운로드하지 않습니다.
- 선택형 iCloud 저장 범위를 메일·회의·루틴·단어장·설정으로 확대했습니다. 연결 정보는 iCloud 키체인을 사용하며 건강정보·OS 권한·다운로드 모델은 제외합니다.
- 회의 전체 음성과 대화 타임라인을 소스의 공통 시각에 맞춰 재생하고, 마지막으로 선택한 음성·요약 언어를 기억합니다.
- 루틴 추천 근거와 일정을 검토·승인할 수 있도록 하고, 지원되는 iOS 기기의 건강·운동 기록은 별도 권한과 동의로 연결합니다.
- 로그인 없이 의견과 선택한 진단을 검토·전송할 수 있습니다. 실제 접수번호를 받은 경우에만 성공으로 안내합니다.
- 재생 설정·파형·할 일 보드·튜토리얼과 Mac 월간 캘린더의 표시를 개선했습니다.
- Mac 비활성 도구 모음 충돌, 모델 미사용 시 불필요한 Metal 초기화, 짧은 회의 FLAC 저장·재생 문제를 수정했습니다.
- 등록 대기 항목을 일괄 AI 정렬·알림·자동 캘린더 등록에서 제외합니다.

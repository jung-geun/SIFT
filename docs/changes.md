# 변경사항

SIFT 앱의 공개 기능 개선과 배포 변경을 기록합니다.

---

## 기록 방식

- 현재 repo에서 확인되는 릴리즈 태그는 `1.0.5` 하나입니다.
- `1.0.0`~`1.0.4`의 세부 변경 이력은 태그나 릴리즈 노트가 없어 추정하지 않습니다.
- 앞으로 배포되는 버전은 이 페이지에 버전별로 추가합니다.

---

## 1.0.5 이후

[App Store에서 SIFT 1.0.9를 무료로 다운로드](https://apps.apple.com/kr/app/sift-to-do-list/id6782752844)할 수 있습니다. 아래 기록은 1.0.5 이후의 개발 소스 변경도 포함하며, 현재 저장소의 모든 변경이 다운로드한 출시 바이너리에 포함됐다는 뜻은 아닙니다.

- **macOS 1.0.10 (6) 심사 제출 (2026-10-16)**:
  - 같은 기준선의 Mac Catalyst 앱을 macOS 26.0 이상용 Apple Silicon·Intel 통합 바이너리로 아카이브하고 Mac App Store 설치 패키지로 내보냈습니다. 실제 패키지의 배포 서명, 샌드박스·프로덕션 권한, 8개 언어와 오픈소스 고지 원본 일치를 확인했습니다. 앱 소스 변경이나 뱅골어 추가는 없습니다.
  - 별도 QA 앱의 합성 in-memory 데이터로 할 일 생성, 실제 키보드 메모 입력·저장·재열기, 더 보기 → 설정, 라이선스 목록·문서 열기·뒤로 가기를 실행했습니다. 캘린더 권한은 부여하지 않고 접근 불가 안내를 확인했습니다. 정식 앱과 사용자 데이터는 건드리지 않았습니다.
  - 업로드 처리 후 정확한 macOS `1.0.10 (6)`을 선택했고, 18:19 현지 시각에 **Waiting for Review** 접수를 확인했습니다. 승인 후 자동 출시·전체 사용자 즉시 제공을 유지했으며 iOS의 기존 심사 요청은 변경하지 않았습니다. 심사 승인·공개 출시 완료는 아직 확인되지 않았습니다.
  - Mac 스토어 설명과 심사 안내를 현재 선택형 연결·데이터 동의 경계에 맞추고 실제 Mac 화면의 한국어 스크린샷 3장(1280×800, 불투명 JPEG)을 등록했습니다. 기존 이미지는 Asset Library에 남겼고 새 버전의 화면·빌드·자동 출시 설정이 재로드 후 보존됨을 확인했습니다.
  - 아카이브는 오류 0·기존 경고 19개로 성공했습니다. Intel 실기기 실행, 실제 계정·iCloud·캘린더 연동, 모든 Mac의 AI/회의 성능이나 새 언어의 네이티브 선택 흐름을 이번 확인으로 보증하지 않습니다. 상세 근거는 저장소의 `ios/UI_TEST_PLAN.md`에 기록했습니다.

- **현재 기준선 심사 제출 1.0.10 (6) (2026-10-16)**:
  - 기존 8개 언어와 현재 iOS/iPadOS 기능을 기준으로 배포 후보를 준비했습니다. 요청에 따라 뱅골어는 이번 후보에 추가하지 않았으며 Android·참고 백엔드의 신규 배포도 포함하지 않습니다.
  - 최종 QA 회귀 검사에서 862개 테스트가 통과했습니다(매개변수 포함 968회, 실패·건너뜀 0). 이 중 9개는 더 보기 설정·튜토리얼·화면 회전·언어 전환과 원문 보존을 실제 시뮬레이터 화면에서 확인하는 UI 여정입니다.
  - 프로덕션 아카이브와 App Store Connect용 IPA 내보내기가 성공했습니다. `pieroot.sift-todo`, 버전 `1.0.10`, 빌드 `6`의 서명, 프로덕션 권한, 8개 언어 리소스와 오픈소스 고지 원본 일치를 확인했습니다. 이는 심사 승인이나 공개 출시 완료를 뜻하지 않습니다.
  - 동일 아카이브를 기존 Xcode 계정으로 업로드한 뒤 App Store Connect에서 정확한 `1.0.10 (6)`의 처리 완료와 심사 접수를 확인했습니다. 현재 상태는 **Waiting for Review**이며 승인 후 자동 출시하도록 설정했습니다. 심사 승인·공개 출시는 아직 확인되지 않았고 공개 바이너리는 `1.0.9`입니다.
  - 기존 한국어 스토어 설명의 모든 기능 오프라인·외부 전송 없음 표현을 새 버전의 선택형 연결·데이터 동의 경계에 맞췄습니다. 한국어 iPhone 4장·iPad 4장을 새 버전에 등록하고 설명·심사 안내·빌드 선택의 저장 결과를 다시 불러와 확인했습니다. App Privacy는 기존 항목과 이용 목적을 유지하면서 계정·기기 식별자와 완료 기록 기반 사용 정보를 추가하고 계정 연결 여부를 정정했습니다. 스토어 설명의 현지화는 기존 한국어이며 앱 자체의 8개 언어 지원과 구분합니다.
  - [소스 PR #18](https://github.com/jung-geun/SIFT/pull/18)의 병합 후 CI와 GitHub Pages 배포가 통과했습니다. 실제 사이트의 홈·소개 이미지·작업 흐름에서 화면 폭 5개와 밝음/어두움 30개 조합의 가로 넘침 없음, 내부 리소스 62개의 HTTP 200 응답, ZIP 브라우저 다운로드·원본 해시 일치·압축 무결성을 확인했습니다. 도표의 한국어 검색·연결 추적·테마 전환도 실행했습니다.

- **8개 언어·더 보기 설정·공개 시각 자료 (2026-10-16, 개발 소스)**:
  - 기존 한국어·영어에 스페인어·일본어·중국어 간체·프랑스어·이탈리아어·독일어를 추가했습니다. 선택/시스템 복원, 지역별 형식·복수형, UI·접근성·권한·오류 안내와 생성 문구의 언어 경로를 연결했습니다. 사용자 제목·메일·회의 원문과 저장 식별자는 바꾸지 않습니다. 음성/AI는 실제 지원 조건을 계속 검사하며, 기존 규칙 분석기의 한국어/영어 원문 문법까지 확장했다는 뜻은 아닙니다.
  - 할 일의 별도 설정 버튼을 없애고 **더 보기 → 설정**으로 통합했습니다. 추가 동작은 기본 도구 모음에 남기며 튜토리얼의 설정 이동·다른 동작 제한도 새 경로를 따릅니다.
  - [소개 이미지](media.html)에 실제 QA 시뮬레이터 캡처 16장으로 만든 한국어·영어 완성 이미지 20장과 ZIP·크기·출처·SHA-256 명세를 제공합니다. iPhone 1206×2622, iPad 2732×2048의 불투명 RGB PNG와 웹/공유 카드입니다. 샘플 할 일만 사용했으며 App Preview 동영상·실제 AI 결과·스토어 업로드가 아닙니다. 캡처용 임시 앱 코드와 UI 드라이버는 제거했습니다.
  - [작업 흐름](workflows.html)에 할 일·메일·루틴, 회의 저장·전사·실패 복구, 선택형 외부 연결의 세 도표와 글 설명·편집 원본을 추가하고 README·사이트 탐색에 연결했습니다. 세 도표는 각각 showcase 9/9, 구성 오류·경고 0으로 생성했고 브라우저 측정과 밝은/어두운 이미지 검토를 별도로 수행했습니다. 모바일 도구 모음의 버튼 잘림을 수정했습니다.
  - `/tmp/sift-eight-language-native-v2-20261016.xcresult`의 단위·UI 합계 864개가 통과했습니다(매개변수 포함 970회, 실패·건너뜀 0). 임시 캡처 코드 제거 후 `/tmp/sift-eight-language-final-ui-20261016.xcresult`의 네이티브 UI 9개도 통과했습니다. 여섯 새 언어의 실제 입력 화면, 언어 전환/시스템 복원 중 원문 보존, 세로/가로의 더 보기 설정 및 튜토리얼 동작을 확인했습니다.
  - 최종 Mac Catalyst 빌드도 오류 0으로 성공했습니다(`/tmp/sift-eight-language-final-catalyst-v2-20261016.xcresult`). 기존 actor 격리·동시성·사용하지 않는 반환값·Metal 도구 경로 경고 14개는 남아 있으며, Catalyst 화면 실행이나 경고 없는 빌드라는 뜻은 아닙니다.
  - 로컬 Jekyll 빌드와 Chromium에서 홈·이미지·흐름 문서의 320·390·768·1024·1440px 및 밝음/어두움 환경 설정 30개 조합을 확인했습니다. 문서 가로 넘침 없음, 내부 자료 54개의 완전한 HTTP 200 응답, 실제 ZIP 다운로드와 소스 해시 일치를 확인했습니다. 카탈로그의 1,680개 UI 키·5개 권한/이름 키는 8개 언어 모두 번역 단위를 갖습니다. 실기기·외부 계정·새 언어의 음성/AI 품질 검증, 웹 배포와 App Store 제출은 수행하지 않았습니다.

- **회의 진행 표시·긴 파형·파일 가져오기 및 할 일 입력 개선 (2026-10-16, 개발 소스)**:
  - 제공된 iPhone `1.0.9 (4)` 진단은 종료 후 Whisper 전사의 `invalidTimestamps`입니다. 기존 Apple 전사가 보존되므로 오류 후에도 전사문을 보고 후속 처리를 할 수 있습니다. 해당 보고서에 원시 시간·stack·MetricKit payload가 없어 정확한 단일 유발 원인이나 발열 인과관계는 단정하지 않습니다. 오류 제목을 회의 처리 오류로 바꾸고 기존 전사 보존과 음성만 저장된 상태를 구분해 안내합니다.
  - 긴 녹음의 파형은 약 0.1초 단위의 피크를 유지하고 화면에 보이는 구간만 그립니다. 세밀한 드래그와 전체 녹음 탐색 슬라이더를 제공하며, 78분 8초 생성 음원의 가져오기·중간 위치 탐색·실제 재생을 iOS 27 시뮬레이터에서 확인했습니다.
  - 전사 대기·모델 로딩·음성 준비·인식/시간 정렬·검사/저장을 구분합니다. 실제 샘플/SDK 시간 콜백의 처리 위치와 경과 시간을 표시하고, 충분한 인식 구간이 확인된 뒤 현재 실행 속도로 잔여 시간·완료 시각을 추정합니다. 모델 로딩·화자 분석·AI 검수·요약 시간은 추정에 포함하지 않으며 디코더가 음성 끝에 도달했다고 저장 완료로 표시하지 않습니다.
  - 회의 화면의 파일 가져오기는 선택한 오디오를 읽기 전용으로 열어 16 kHz mono FLAC과 독립 회의 기록으로 저장한 후 기존 오프라인 전사·후처리에 연결합니다. 원본 파일은 보존하고 가져오기가 만든 디렉터리만 취소/저장 실패 시 정리합니다. 모델 미설치·전사 실패 후에도 음성은 재시도용으로 남으며 Apple 원문이나 성공 전사를 만들지 않습니다. 마이크 권한·자동 모델 다운로드·외부 AI 업로드는 시작하지 않습니다.
  - 할 일 목록에는 알려진 AI 엔진의 성공 기록에만 작은 반짝임 표시를 붙이고 상세 근거는 유지합니다. 규칙 처리·대체 결과·미분석 항목은 제외합니다. 새 할 일의 추가 옵션은 폼 내부 저장 safe-area를 확보하며, 높이가 좁은 가로 화면은 상단 저장을 유지합니다. 키보드 닫기는 저장과 별개입니다.
  - 실제 Files 선택→로컬 Whisper 추론→저장된 전사 확인과 할 일 입력 6개 시나리오가 `/tmp/sift-meeting-native-v3-20261016.xcresult`에서 통과했습니다. 약 11초 합성 영어 음성을 실제로 인식한 결과이며, 후속 텍스트 처리는 시뮬레이터의 기존 규칙 대체 경로였습니다. 긴 음원의 Whisper 처리 속도·한국어 품질·실기기 발열 검증이나 출시 반영을 뜻하지 않습니다.
  - 임시 검증 코드를 제거한 최종 iOS 27 QA 회귀는 단위 테스트 858개와 네이티브 UI 9개가 모두 통과했습니다(매개변수 포함 총 973회, 실패·건너뜀 0). 결과: `/tmp/sift-meeting-final-regressions-20261016.xcresult`. README·개인정보 처리방침·회의 단계 문서·UI 검증 기록과 한국어/영어 문자열을 갱신했습니다.

- **IMAP 연결·메일 조회 검증 (2026-10-15)**: Gmail·Outlook의 이메일 연동 정보 확인과 다시 연결에서 TLS 연결·로그인·받은편지함 선택뿐 아니라 최신 메일 한 건의 헤더 조회·파싱까지 성공해야 ‘연결됨’으로 표시합니다. 새 앱 비밀번호도 이 검증 뒤에만 저장합니다. 받은편지함이 명시적으로 비어 있으면 정상 연결로 처리하고, 실패 시 세션 상태·연결을 정리하되 기존 앱 비밀번호는 보존합니다. 조회에는 `BODY.PEEK`를 사용해 읽음 상태를 바꾸지 않으며 전체 메일함을 스캔하지 않습니다. 설정에는 실패 원인과 다시 연결 동작을 표시합니다.

- **회의 화자 구분 베타 (2026-09-27)**: 베타 기능에서 기기별로 켜고 별도 버튼으로만 Hugging Face의 고정 Nemotron 3 Core ML 모델(FluidAudio 0.17.4, 검증 대상 202,106,426 bytes)을 설치합니다. 녹음 중에는 임시 화자를 표시하고 종료 후 저장된 전체 음성을 기기에서 다시 분석해 화자 라벨을 보정합니다. 최대 8명의 회의별 화자 이름·수동 배정을 저장하며, 기존 쉼표 구분 화자 편집기는 화자 선택·이름 편집으로 교체했습니다. 저장 후 화자 분석만 중지·재시도할 수 있고, 녹음 중 설정 변경은 다음 녹음부터 적용합니다. 시뮬레이터 회의 복구·취소·경합 테스트 37회 실행은 통과했지만 실제 iPhone 품질·지연·발열, 한국어·8인 정확도와 라이브 p95는 아직 검증되지 않았습니다. 앞선 실기기 녹음 QA는 복구 manifest 오류로 저장 전에 실패하여 원인을 추가 조사 중입니다.
- **Laya 다국어 Core ML 교체 (2026-09-27)**: 베타 TODO 우선순위 모델을 영어 전용 자체 게시 그래프에서 `FluidInference/laya-coreml`의 revision `7b8d7a2b7e28e746c6ecaad44bbcd5cf251a4fcc`에 고정된 multilingual e8 L256/32-option 그래프로 교체했습니다. 원본 한국어·영어를 번역 없이 처리하며 약 483 MB를 수동 설치하고 모델·토크나이저 파일의 크기·SHA-256을 검증합니다. Mac 실제 Core ML `CPU_AND_NE` 요청 실행에서 균형 48개 샘플 중 영어 13/24, 한국어 16/24, warm 중앙값 9.85 ms·p95 9.88 ms였습니다. 품질 채택 기준 미달이며 ANE 실제 배치 여부는 미관측입니다. 연결된 실제 iPhone 18 Pro (iOS 27.0)에 검증된 모델 디렉터리를 배치하고 실제 mmBERT 토크나이저와 프로덕션 Core ML 러너로 긴급 한국어 세무 할 일을 추론한 결과, 정상 통과(결과 `now`, `xcresult /tmp/sift-laya-device-runtime-20260927.xcresult`)했습니다. 아래의 2026-09-26 실기기 Laya 기록은 교체 전 구형 아티팩트에 한정됩니다.

- **할 일 스와이프 오작동 수정**: 목록 행의 중복 드래그 제스처를 제거하고 시스템 스와이프 액션으로 통일했습니다. 부분 스와이프는 삭제·완료·되돌리기 버튼만 표시하고, 버튼 탭 또는 전체 스와이프에서만 동작을 실행합니다. 등록 대기열의 오른쪽 스와이프는 완료가 아닌 진행중 승격입니다. iOS 27.0 및 26.5 iPhone 시뮬레이터에서 스와이프 UI 테스트 6개와 기존 상세 편집 테스트 1개를 각각 통과했고, 두 OS의 iPad 시뮬레이터에서 대기열의 부분/전체 승격 테스트 2개를 각각 통과했습니다. 실기기 스와이프 검증은 진행하지 않았습니다.

- **배포 파이프라인**: TestFlight 배포 workflow가 `v*` 태그뿐 아니라 `1.0.5` 같은 숫자 태그도 감지하도록 조정했습니다.
- **패키지 무결성**: Xcode Cloud 사전 빌드에서 확인하는 `Package.resolved` SHA-256 기준값을 현재 패키지 상태에 맞췄습니다.
- **Apple Foundation Models 가용성 안내**: 실제 Apple Intelligence/Siri AI 활성화 조건에 맞춰 AFM 경로를 중앙 가용성 판정으로 통일하고, 미지원 환경에서는 Qwen 또는 통계 기반 폴백을 안내하도록 설정 화면 문구를 정리했습니다.
- **전체 받은편지함 탐색**: 메일 탭에서 Gmail 받은편지함을 기간·읽음 여부 제한 없이 페이지 단위로 탐색하고, 본문 확인·읽음 처리·휴지통 이동을 즉시 동기화하도록 개선했습니다.
- **통합 로컬 검색**: 검색 탭에서 TODO, 현재 연결된 메일 계정의 받은편지함 로컬 캐시, 디코딩된 회의 결과를 기기 안에서 함께 검색하도록 추가했습니다. 메일 본문과 원시 회의 전사·오디오는 검색 색인에 포함하지 않습니다.
- **Laya provider — 처리 시각 추천 추가(영어 전용)**: 기존 이진 우선순위 결정에 더해, 마감·캘린더 일정·같은 세션에서 이미 배정된 다른 TODO와 겹치지 않는 시간대 중에서 처리 시각을 추천하도록 확장했습니다. 모델은 최대 4개 선택지를 마스킹으로 지원하는 새 Core ML 그래프(`pieroot/laya-priority-coreml`, `61693f7bf4b02ff4b63a80acc18fd140e614350d`)로 교체했으며, 다운로드는 여전히 베타 기능에서 수동으로만 시작됩니다. 다운로드한 파일은 매니페스트에 기록된 SHA-256과 정확히 일치해야만 추론에 사용되고, 실패 시 기존 우선순위 경로로 폴백합니다.
- **베타 분석 경로 안정화**: 우선순위 결과를 화면에 순차 적용할 때도 선택한 provider 기록이 유지되도록 수정했습니다. Laya로 처리할 수 없어 규칙 요약이 저장된 메일은 사용 가능한 AFM으로 전환하면 다시 분석합니다.
- **우선순위 결과 저장 보장**: AI 정리 결과를 적용한 뒤 완료 전에 명시적으로 저장합니다. 자동 저장을 기다리지 않고 앱을 종료하면 새 결과가 사라지던 문제를 실기기에서 재현·수정했습니다.
- **iOS 26.5 실행 중단 수정**: Xcode 27(Swift 6.4) 툴체인이 `swift-collections` 1.7.0의 새 borrowing-iterator 코드(`InternalCollectionsUtilities`)를 컴파일하면서, iOS 27 런타임에만 있는 `_swift_initBorrow` 심볼을 앱 바이너리에 강하게(weak 아님) 요구해 iOS 26.5에서 실행 즉시 `dyld ... Symbol not found` 로 종료되는 문제가 있었습니다. `swift-collections`를 해당 코드가 없는 1.6.0으로 고정했습니다. iOS 26.5 시뮬레이터에서 정상 실행 확인; iOS 26.0 및 iOS 26.x 실기기 검증은 아직 진행 전입니다.
- **회의 완료 표시 정정**: 최종 요약 저장이 실패하면 처리 완료로 표시하지 않고 실제 오류를 전달합니다. 최종 저장 실패 회귀 검증을 포함한 회의 테스트 19개를 통과했습니다.
- **한국어 표시 누락 수정**: 번역값이 키와 같다는 이유로 한국어 문자열을 누락 처리하던 로직을 missing-key sentinel 방식으로 수정했습니다. 간헐 현상이 아니라 lookup 버그였으며, 실기기에서 `녹음 시작`의 한국어 표시를 확인했습니다.
- **실기기 검증 (2026-09-26)**: iPhone 18 Pro / iOS 27.0에서 수동으로 받은 Laya 모델로 한국어·영어 TODO 13개를 처리했습니다. 재실행 후에도 13개 모두 `aiEngine=Laya`, 요청 provider `laya`, 빈 fallback 사유와 추천 처리 시각이 저장되어 있음을 확인했습니다. 동일 실행에서 기존 회의의 저장된 요약과 최종 전사문도 다시 열어 확인했습니다. 모델 정확도 기준 미달과 추천 품질 제한은 그대로입니다.
- **최종 회귀 검증**: iOS 27.0 시뮬레이터의 `todoTests` 454개를 모두 통과했습니다. 실기기 검증용 임시 UI probe·scheme은 저장소에서 제거하고 로컬 증거 폴더에 보관했습니다. 실기기 실행에서 `UnexpectedTerminationRecoveryService`의 SwiftUI Binding actor-isolation 경고는 남아 있으며, 이번 우선순위·저장 검증 통과와 별개의 위험입니다.

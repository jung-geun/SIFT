# 변경사항

SIFT 앱의 공개 기능 개선과 배포 변경을 기록합니다.

---

## 기록 방식

- 현재 repo에서 확인되는 릴리즈 태그는 `1.0.5` 하나입니다.
- `1.0.0`~`1.0.4`의 세부 변경 이력은 태그나 릴리즈 노트가 없어 추정하지 않습니다.
- 앞으로 배포되는 버전은 이 페이지에 버전별로 추가합니다.

---

## 1.0.5 이후

[App Store에서 SIFT 1.0.9를 무료로 다운로드](https://apps.apple.com/kr/app/sift-to-do-list/id6782752844)할 수 있습니다. 아래 기록은 1.0.5 이후의 개발 소스 변경도 포함하며, 현재 저장소의 모든 변경이 다운로드한 출시 바이너리에 포함됐다는 뜻은 아닙니다.

- **하위 문서 테마 통일 (2026-10-14)**: 변경사항·Outlook 연결 안내·개인정보 처리방침·서비스 약관과 기술 문서 3개에 홈과 같은 색상·서체·헤더·푸터를 적용했습니다. 공통 문서 탐색·현재 페이지 표시·접이식 목차·맨 위로 이동을 제공하며, 표와 코드 블록은 좁은 화면에서 문서 전체를 밀어내지 않고 내부에서 스크롤됩니다. 기존 본문·섹션 앵커·문서 URL은 보존하고 변경사항 상단의 중복 탐색과 렌더링되지 않던 HTML 제목 래퍼를 제거했습니다.
  - 로컬 Jekyll 빌드와 Chromium에서 문서 7개의 320·390·768·1024·1440px 화면 35개를 확인했습니다. 기존 본문·표·링크·섹션 ID 보존, 가로 넘침 없음, 본문 바로가기·목차 키보드 조작·표 가로 스크롤, JavaScript 없는 탐색·동작 줄이기, 홈으로 돌아가는 다운로드 링크·기존 앱 화면 탭과 문서 하단 GitHub 새 탭 열기를 검증했습니다. 테마 작업은 앱 코드나 정책 내용·기존 배포 경로를 바꾸지 않습니다.

- **소개 페이지 GitHub 접근 링크 (2026-10-13)**: 사용자 요청에 따라 소개 페이지 최하단에 [GitHub ↗](https://github.com/jung-geun/SIFT) 링크를 추가했습니다. 새 탭 안내와 `noopener noreferrer`를 적용하고, 기존 다운로드·도움말·정책 링크와 모바일 상단 메뉴는 유지합니다. 1440·390·320px 화면에서 링크 표시·가로 넘침 없음과 실제 클릭 후 로그인하지 않은 브라우저에서 저장소가 열리는 것을 확인했습니다. 테마 자동 버튼이나 저장소 공개 설정은 변경하지 않았습니다.

- **소개 페이지 개편·App Store 다운로드 (2026-10-13)**: TestFlight 설치 안내를 공개 App Store 다운로드로 교체하고, 일반 사용자를 위한 짧은 한국어 소개·실제 앱 화면·사용 흐름 중심으로 홈을 개편했습니다. 공개 App Store의 할 일·새 할 일·캘린더·설정 화면 4개와 생산용 SIFT 아이콘, 공식 한국어 다운로드 배지를 사용합니다. 화면은 공개 스토어 자료임을 명시하며 미출시 소스 기능이나 검증하지 않은 Mac 지원을 출시 기능으로 안내하지 않습니다. 별도 홈 레이아웃을 사용하고 나머지 문서의 Cayman 테마와 도움말·정책·약관·문의 경로는 유지합니다.
  - 메일 확인 → 내용 검토 → 저장하고 실행의 3단계 흐름과 선택형 연결·외부 AI 데이터 전송 경계를 시각적으로 설명합니다. 화면 탭의 키보드 탐색·이전/다음·원본 크게 보기, 유한 모션의 멈춤/재생·다시 보기, 초기·실행 중 동작 줄이기 설정과 JavaScript 없는 대체 화면을 제공합니다. 브라우저용 프레임워크·분석 도구·추가 런타임 의존성은 도입하지 않았습니다.
  - GitHub Pages 기본 Markdown 플러그인을 포함한 로컬 Jekyll 빌드와 Chromium의 320·390·768·1024·1440px 화면을 확인했습니다. 320px에서 장식 배경이 12px 넘치는 문제는 부모 폭에 맞춰 제한해 수정했고 세로 스크롤바를 제외한 실제 표시 폭 기준으로 가로 넘침이 없음을 확인했습니다. 키보드·포인터·탭 순환, 모션 멈춤 뒤 다운로드 내용 보존, 초기·실행 중 동작 줄이기, JavaScript 없는 4개 화면·기본 링크 탐색과 문서 링크 4개의 HTTP 200을 확인했습니다. 로컬 미리보기 검증이며 GitHub Pages 배포나 앱·릴리즈 워크플로우 변경은 수행하지 않았습니다.

- **소개 페이지 저장소 링크 제거 (2026-10-13)**: 비공개 저장소로 연결되는 상단 `View on GitHub` 버튼과 하단 저장소 링크를 제거했습니다. TestFlight·변경사항·개인정보 처리방침·서비스 약관 링크는 유지합니다.

- **배포 파이프라인**: TestFlight 배포 workflow가 `v*` 태그뿐 아니라 `1.0.5` 같은 숫자 태그도 감지하도록 조정했습니다.
- **패키지 무결성**: Xcode Cloud 사전 빌드에서 확인하는 `Package.resolved` SHA-256 기준값을 현재 패키지 상태에 맞췄습니다.
- **CI 검증**: GitHub Actions iOS CI가 빌드·테스트 실패를 성공으로 표시하던 문제(파이프 종료 코드 누락과 `|| xcodebuild` 재실행)를 고쳐, 실제로 빌드하고 `todoTests`를 실행하며 결과가 통과가 아니거나 통과한 테스트가 없으면 실패하도록 했습니다. `backend/meeting-api` 변경은 별도 workflow에서 테스트·빌드하고, CI 형태는 `scripts/check_ci_contract.py` 계약 검사로 고정합니다.
- **Apple Foundation Models 가용성 안내**: 실제 Apple Intelligence/Siri AI 활성화 조건에 맞춰 AFM 경로를 중앙 가용성 판정으로 통일하고, 미지원 환경에서는 Qwen 또는 통계 기반 폴백을 안내하도록 설정 화면 문구를 정리했습니다.
- **전체 받은편지함 탐색**: 메일 탭에서 Gmail 받은편지함을 기간·읽음 여부 제한 없이 페이지 단위로 탐색하고, 본문 확인·읽음 처리·휴지통 이동을 즉시 동기화하도록 개선했습니다.
- **통합 로컬 검색**: 검색 탭에서 TODO, 현재 연결된 메일 계정의 받은편지함 로컬 캐시, 디코딩된 회의 결과를 기기 안에서 함께 검색하도록 추가했습니다. 메일 본문과 원시 회의 전사·오디오는 검색 색인에 포함하지 않습니다.

## 1.0.5 — 현재 배포 기준선 (2026-06-30)

### 사용자 기능

- **메일 기반 할 일 추출**: Gmail OAuth 연동으로 최근 메일을 읽고 마감·요청성 항목을 TODO 후보로 추출합니다.
- **원본 메일 확인**: 메일 탭과 TODO 상세에서 로컬 메일 캐시, Gmail 앱, Mail.app, Gmail 웹 순서로 원본 메일을 열 수 있습니다.
- **온디바이스 우선 이메일 분석**: 이메일 본문은 기본적으로 기기 내 분석 경로에서 처리하고, Gemini 본문 분석은 사용자가 별도로 허용한 경우에만 사용합니다.
- **캘린더 연동**: 마감이 있는 TODO를 EventKit 캘린더에 등록하고, 시스템 캘린더 변경을 TODO 상태와 동기화합니다.
- **AI 우선순위 정렬**: Apple Foundation Models 조건부 경로, MLX Qwen, Gemini API 선택 경로, 휴리스틱 폴백을 사용해 TODO 우선순위를 계산합니다.
- **행동 패턴/페르소나 분석**: 완료 시간대, 태그별 처리 속도, 마감 준수율을 바탕으로 개인화된 정렬 정보를 만듭니다.
- **온보딩과 설정 화면 정리**: 최초 실행 튜토리얼, iCloud 동기화 선택, 이메일·캘린더·AI·메모리 등 설정 상세 화면을 분리했습니다.
- **iCloud 선택 동기화**: TODO·페르소나·Audit·메모리 분석은 선택적으로 CloudKit Private DB에 동기화하고, 이메일 본문 캐시는 로컬 전용 컨테이너에 둡니다.

### 배포 준비/내부 품질

- **Gemini 라우팅 안정화**: Gemini API 키와 모델 설정을 분리하고, 실패 시 라우팅 오류와 폴백 경로가 드러나도록 정리했습니다.
- **테스트 보강**: Gmail, Gemini, AI 라우팅, 이메일 수집, 튜토리얼, 설정 저장소 회귀 테스트를 추가·갱신했습니다.
- **CI 무결성 검사**: Xcode Cloud 사전 빌드에서 `Package.resolved` 해시를 검증해 Swift Package 변경 누락을 빠르게 잡습니다.

## 이전 버전

`1.0.5` 이전 버전은 현재 repo에서 세분화된 태그나 릴리즈 노트가 확인되지 않습니다. 이전 작업은 `1.0.5` 기준선에 포함된 상태로 기록하고, 앞으로의 변경은 이 페이지에 버전별로 남깁니다.

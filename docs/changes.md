# 변경사항

현재 앱의 심사 제출 변경사항과 이미 공개된 버전 기록을 구분합니다. 심사 중인 기능이 다운로드한 출시 앱에 모두 제공된다는 뜻은 아닙니다.

<a id="version-1-0-13-12"></a>
## 1.0.13 (12) — 배포 준비·미출시

iCloud 반복 인증·대량 저장 부하와 회의 오류 보고를 수정한 패치입니다. iOS·universal Mac 배포를 준비 중이며 업로드·심사 접수·승인·공개 완료는 각각 별도로 확인합니다. **2026-10-30 배포 준비 중 App Store Connect 확인 기준**, 기존 Mac `1.0.12 (11)`은 `Ready for Sale`, iOS는 `Waiting for Review`였습니다. iOS 대기 제출은 수정된 패치로 교체하며, 아래 `1.0.12` 설명은 표시된 확인 시각의 과거 기록입니다.

- 자동 동기화의 보호된 연결 정보 확인은 인증 창 없이 수행하고, 별도 승인 작업에서 인증 목적·현재 그룹·취소·대기 상태를 안내합니다. 이미 검증한 키체인 기록을 재사용하면서 기존 보호 수준을 유지합니다.
- 작은 동기화 변경을 제한된 묶음으로 저장해 디스크 쓰기와 CloudKit 내보내기 요청을 줄였습니다. 원문·리비전 ID·중간 실패 후 재시작과 취소 처리는 보존합니다.
- 회의 시스템 오디오 오류의 실패 단계·SDK 코드를 유지하고 Mac 캡처 권한을 안내합니다. 진단 수집을 나중에 허용해도 오류를 잃지 않습니다.
- 오류 보고 작성 취소·전송 실패 후 진단 검토·초안·제출 ID를 유지하고, 실제 진단 접수 성공일 때만 전달 완료로 처리합니다. 관련 안내는 8개 앱 언어에 반영했습니다.

<a id="version-1-0-12-11"></a>
## 1.0.12 (11) — 심사 접수·공개 전

**2026-10-30 06:51 KST 확인 기준**, iOS·universal Mac `1.0.12 (11)`의 업로드 처리가 모두 `VALID`이며 두 플랫폼 모두 **Waiting for Review**로 심사 접수됐습니다. **승인 후 자동 출시**하며 아직 공개된 버전은 `1.0.11`입니다. [PR32](https://github.com/jung-geun/SIFT/pull/32)의 [최종 CI](https://github.com/jung-geun/SIFT/actions/runs/40959391692)·보안 검사를 통과하고 main에 반영했습니다. 앱·확장의 실제 버전, Mac 양쪽 아키텍처·네이티브 지원 번들, 배포 서명·프로덕션 권한과 원음 보존·재생을 확인했습니다. 아카이브·업로드·심사 접수는 승인·공개 완료와 구분합니다.

- 모바일 캘린더의 월 표시 밀도·연도·일·여러 날 보기, 연속 스크롤·핀치·오늘 이동과 좁은 iPad 화면을 개선했습니다. Mac에서는 빈 시간 클릭·범위 드래그·일정 가장자리 크기 조절·우클릭 편집을 지원합니다.
- 일정 직접 수정·삭제 시 기존 할 일 연결·완료 기록·반복 일정·시간대 경계를 보존하고, 삭제한 일정이 자동 등록으로 다시 생기지 않도록 보완했습니다.
- 실제 입력 파형, iPhone·iPad의 Live Activity와 Mac 메뉴 막대 녹음 표시를 추가했습니다. 실시간 전사는 Apple 기본 모델을 사용하며 선택형 Whisper는 종료 후 처리에만 사용합니다. 전사 실패와 원음 저장 실패를 구분합니다.
- Mac 오디오 가져오기에 선택 파일 읽기 권한과 네이티브 열기 패널을 적용했습니다. 원본 변경 없이 로컬 저장·재생하며 iPhone·iPad 파일 선택 경로를 유지합니다.
- 설정을 AI·회의·할 일·루틴의 역할에 맞게 정리했습니다. Apple Intelligence의 실제 지원·준비 상태와 로컬 모델 사용 동의를 구분하며, 외부 분석은 연결된 계정·지원 지역·개별 공유 동의가 있을 때만 실행합니다.
- 메일 동기화 성공 팝업을 없애고 기기에서 아직 열지 않은 새 메일에 파란 점을 표시합니다. 할 일 검색·필터를 고정하고 Duo 초안 유지, 빈 공간 두 번 클릭·터치 생성, Mac 버튼·편집·명암 대비를 개선했습니다.

다음 항목별 기록은 개발·검증 당시의 범위를 보존합니다. 새 버전의 실제 스토어 상태는 별도 배포 확인 기록을 기준으로 합니다.

## 개발 소스 — iCloud 대량 저장·로그 폭증 완화 (미출시)

- CloudKit 전송 저장소에서 작은 변경마다 개별 커밋하던 경로를 최대 64개·합계 4MiB의 제한된 묶음으로 바꿨습니다. 로그를 숨기지 않고 내보내기 요청과 WAL 쓰기를 증폭시키던 앱의 저장 횟수를 줄입니다. 큰 파일·기존 원문·리비전 ID·장애 복구 저널은 유지합니다.
- 취소·계정 변경으로 무효화된 미커밋 묶음은 되돌리고, 나중 항목의 읽기 실패가 앞서 검증한 변경의 저장을 계속 막지 않도록 합니다. 변경 없는 반복 확인은 새 리비전을 만들지 않으며 실제 iCloud 전송 완료는 Apple 내보내기 결과로 구분합니다.

## 개발 소스 — 반복 키체인 인증·회의 오류 보고 수정 (미출시)

- iCloud 자동 동기화가 보호된 계정 연결 정보를 반복해서 읽으며 인증을 재요청하던 경로를 분리했습니다. 자동 확인은 인증 창 없이 실행하고 별도의 연결 정보 승인 작업에서만 기기 인증을 사용합니다. 취소·실패 시 해당 시도를 종료하고, 연결 정보 승인 대기와 앱 데이터 전송 상태를 구분합니다.
- 보호된 키체인 항목의 비대화형 조회가 막힌 것을 항목 삭제로 오인해 동기화 완료 기록을 남기지 못하던 문제를 수정했습니다. 실제 읽기·저장으로 확인한 기록만 재사용하며, 자격 증명의 보호 수준과 기존 데이터를 유지합니다.
- 회의 시스템 오디오 오류의 원래 SDK 도메인·코드·실패 단계를 보존하고 Mac 캡처 권한 안내를 제공합니다. 진단 수집을 나중에 허용해도 오류가 소실되지 않도록 보고서 표시를 하나의 오류 스냅샷으로 묶었습니다.
- 오류 보고 작성 취소 시 같은 진단 검토와 초안을 유지하며, 전송 실패 코드·접수번호·접수 후 로컬 처리 결과를 구분합니다. 명시적인 최종 전송 동의와 원문 보존을 유지하고 바뀐 안내를 8개 앱 언어에 반영했습니다.



## 개발 소스 — Mac 오디오 파일 가져오기 수정 (미출시)

- Mac 앱의 사용자 선택 파일 읽기 권한 누락을 수정했습니다. 전체 디스크나 선택 파일 쓰기 권한은 추가하지 않습니다.
- Mac에서는 분리된 SwiftUI/UIKit 표시 호스트 대신 실제 창에 연결된 네이티브 열기 패널을 사용합니다. 선택·취소·다시 열기와 외부 오디오의 로컬 저장·재생을 확인했으며 원본은 변경하지 않습니다. iPhone·iPad의 파일 선택 경로는 유지합니다.


## 개발 소스 — Mac 강조색·캘린더 직접 조작·빈 공간 생성 (미출시)

- Mac의 작업 배경·카드 표면을 구분하고 파란색 주요 동작·회의 섹션, 보드의 상태 아이콘·개수로 위계를 보강했습니다. 라이트·다크 모드와 기존 의미색 대비를 유지합니다.
- 캘린더 날짜의 더블 클릭과 하루 창 안의 추가 버튼·빈 시간 클릭으로 새 일정을 엽니다. 빈 시간 드래그로 시작·종료를 함께 지정하고, 일정 위·아래 가장자리를 드래그해 시간을 늘리거나 줄입니다. 실제 저장은 기존 EventKit 쓰기 대상·반복 범위 확인을 사용합니다.
- 하루 일정은 좌클릭 편집·우클릭 시간 조정/삭제를 지원하며, 마지막 일정이 없어도 창을 줄이거나 중앙으로 재배치하지 않고 시간표와 추가 동작을 유지합니다. 짧은 자정 일정도 본문·양쪽 가장자리의 입력 영역을 유지합니다.
- 직접 변경한 일정의 기존 할 일 연결은 과거·30일 밖의 항목과 분리된 반복 발생분도 즉시 갱신합니다. 다른 캘린더·이전 발생분·독립적인 할 일과 완료 기록을 보존하고, DST 날짜·반복 시각의 정확한 경계를 유지합니다.
- 연결된 수동·메일 할 일의 일정을 직접 삭제할 때 외부 식별자를 지우지 않아 자동 등록·다음 동기화에서 일정이 재생성되는 것을 막습니다. 기존 할 일 자체와 완료 기록은 보존합니다.
- 할 일의 빈 컬럼·카드 아래·컬럼 사이를 더블 클릭하거나 빠르게 두 번 터치하면 기존 새 할 일 편집기를 엽니다. 카드·컨트롤·검색 결과에서는 잘못 생성하지 않으며 저장·취소·드래그·스크롤 경로를 유지합니다.


## 개발 소스 — Mac 녹음 표시·전사·편집 화면 (미출시)

- Mac의 중복 앱 상단 녹음 캡슐을 제거하고 실제 시스템 메뉴 막대에 녹음·일시 정지·경과 시간을 표시합니다. ‘녹음 열기’는 해당 녹음 창을 활성화하고 녹음 제어 화면으로 돌아갑니다. 공개 AppKit 지원 번들을 사용하며 위치는 macOS가 제어합니다. 노치 고정이나 Mac용 다이내믹 아일랜드를 가장하지 않습니다.
- 실시간·저장된 그룹·개별 전사에서 같은 화자의 반복 제목·여백을 줄였습니다. 짧고 인접한 미확정 발화만 충돌 없는 앞뒤 화자 근거를 바탕으로 표시상 연결하며 원래 판정·전사·수동 편집은 보존합니다. 긴 미확정 구간·동시 발화·다른 소스는 계속 구분합니다.
- Mac 할 일 상세의 완료·삭제를 작은 네이티브 버튼으로 바꾸고 추가·상세 편집의 취소를 저장 바로 왼쪽에 배치했습니다. 실제 저장·폐기·삭제 확인은 유지합니다.
- Mac 도구 모음 버튼에 네이티브 고유 크기를 지정하고 소프트웨어 키보드용 완료 항목을 제외했습니다. 밝은 화면의 콘텐츠·카드 표면과 강조색·보조 글자 대비를 조정하며 iPhone·iPad의 기존 그룹 배경은 유지합니다.

## 개발 소스 — 설정·설명 정리와 Apple Intelligence 기본 경로 (미출시)

- 할 일의 중복 AI 제공자 설정을 없애고 계정·연결 관리는 설정 → AI로 통합했습니다. 건강·운동 기록은 루틴 학습·추천 안에서만 엽니다.
- 설정 → 회의를 분리했습니다. 기본 화자 구분은 Nemotron이며, 사용을 끄면 다음 녹음의 화자 모델 처리를 생략합니다. 기존 끄기 선택과 직접 설치·취소·삭제는 유지합니다.
- Whisper 고급 전사는 회의 설정의 선택형 베타입니다. 녹음 종료 후 더 큰 모델로 재전사하며 추가 배터리·시간이 필요함을 안내합니다. 자동 언어 모드도 녹음 중에는 원음만 저장하고 종료 후 감지·전사하므로 라이브 Whisper를 로드하지 않습니다. 음성 언어를 직접 고른 Apple 실시간 전사는 유지합니다.
- Apple Intelligence를 기본으로 사용합니다. 지원 기기의 일시적 비활성·모델 준비 상태를 다른 모델 사용 동의로 취급하지 않고, 미지원 기기에서만 베타 로컬 모델 대체를 직접 선택할 수 있습니다. 모델이 없으면 규칙으로 처리합니다.
- 페르소나·행동 분석의 GPT 재분석은 활성화된 OpenAI 계정이 연결되어 있을 때만 표시합니다. 일반 분석이 할 일 정렬의 외부 제공자 선택을 따라 자동 전송하던 경로도 제거하고, 연결·동의 철회 시 고급 요청·미리보기의 늦은 적용을 차단합니다.
- 같은 연결 조건을 루틴의 외부 해석에도 적용해 미연결 상태의 불필요한 GPT·동의 항목을 숨겼습니다. 로컬 모델 목록의 번역되지 않은 수식어도 제거했습니다.
- 로컬 서술 모델의 출력 언어 지원을 추론 전에 확인합니다. MiniCPM5가 지원하지 않는 언어에서는 기존 규칙 기반 페르소나·행동 결과를 유지하고 불필요한 모델 처리를 시작하지 않습니다.
- 설정·메일·회의·캘린더·루틴·온보딩의 반복 설명을 줄이고 권한·원문 보존·처리 한계·모델 귀속 고지는 유지했습니다. 변경 문구 51개를 8개 앱 언어에 반영했습니다.

## 웹사이트 — 소개 페이지 방문 분석 (2026-10-29 배포)

## 개발 소스 — 모바일 캘린더 보기·탐색 대응 (미출시)

- iPhone·iPad에서 월 보기의 간략히·스택·세부사항·목록을 전환할 수 있습니다. 기본 캘린더처럼 월 경계의 주를 해당 월 날짜만으로 나누고, 손가락으로 연속 스크롤하거나 핀치로 표시 밀도를 바꿀 수 있습니다. Mac의 기존 주간 셀 방식은 유지합니다.
- 연도 전체 보기에서 월을 선택하고, 월의 날짜를 누르면 일 보기로 이동합니다. 일 보기의 좌우 스와이프는 하루, 상단 주간 날짜 줄의 좌우 스와이프는 한 주씩 이동합니다. 뒤로 가기는 선택한 날짜의 월 시작으로 돌아갑니다.
- 월의 목록은 선택한 날짜의 일정을 아래에 표시하고, 일 보기의 목록은 빈 날짜를 건너뛰는 시간순 일정 목록을 표시합니다. 여러 날 보기는 두 날짜의 시간표를 나란히 표시하며, 가로 화면에서는 일·주·월·연도 전환을 제공합니다.
- 오늘이 월 화면에 보이지 않으면 오늘의 달로 이동하고, 이미 보이면 오늘의 일 보기를 엽니다. 기존 일정·할 일 편집, 취소 처리와 제한된 범위의 일정 조회를 그대로 사용합니다.
- 월 화면에서 가로로 회전해 목록을 여는 경로에서도 초기 일정과 이후 페이지가 정상 반영되도록 조회 조건을 통일했습니다. 여러 페이지를 불러온 뒤 캘린더 선택·시간대를 바꾸면 선택 날짜부터 다시 읽어 앞쪽 일정이 누락되지 않게 했습니다. 좁은 iPad 창에서는 사이드바를 접어 월 화면 너비를 확보합니다.
- 모바일 하단의 전체 너비 작업 줄을 없애고, ‘오늘’만 좌하단의 작은 둥근 Liquid Glass 버튼으로 표시합니다. 하단 캘린더 선택·새로고침 버튼은 제거하며 Mac의 기존 도구 모음은 유지합니다.

## 개발 소스 — 캘린더 동작 구조·일정 조회 최적화 (미출시)

- Apple 기본 캘린더의 실제 월 보기에서 연속·부분 스크롤, 월 제목 전환, 오늘 이동과 날짜 상세 전환을 비교했습니다. 비공개 구현을 복제하는 대신 기존 네이티브 주간 셀 재사용과 정확한 스크롤 위치 복원을 유지하고, 월 제목은 화면 앞쪽에 보이는 주의 날짜를 따르도록 조정했습니다.
- 일정 조회와 화면 탐색을 분리했습니다. 최대 7개월의 읽기 결과를 재사용하고 새로 들어오는 연속 날짜 범위만 추가 조회합니다. 처음 열거나 새로고침할 때도 7번이 아닌 한 번의 범위 조회를 사용하며, 캘린더 선택·권한·시간대·원본 일정 변경 시에는 이전 캐시를 폐기합니다.
- 일정이나 할 일이 이동·수정·삭제되면 영향받는 이전·새 주만 갱신하고 다른 주의 배치는 보존합니다. 변경 없이 날짜 상세를 닫을 때 불필요하게 전체 일정을 다시 읽지 않으며, 시스템 날짜 변경 시 오늘 표시를 갱신합니다. 반복 일정의 개별 발생분, 다일 일정과 자정 경계 처리는 유지합니다.
- iPad 날짜 상세 팝오버가 너무 좁아 날짜 제목이 잘리던 문제를 수정했습니다. 세로·가로 화면에서 날짜 전체와 닫기 버튼을 함께 표시하고, 휴대폰의 전체 너비 상세 화면은 유지합니다.

## 개발 소스 — 캘린더 스크롤·메일 표시·할 일 새로고침 (미출시)

- 휴대폰과 iPad에서도 Mac과 같은 연속 주간 캘린더를 세로로 스크롤할 수 있습니다. 주별 날짜·일정 배치를 캐시하고 스크롤 중 불필요한 재구성을 줄였으며, 오늘·이전/다음 달 이동과 명시적 캘린더 동기화를 유지합니다.
- 메일 새로고침 때 반복되던 동기화 성공 팝업을 제거했습니다. 앱에 새로 가져왔지만 아직 열지 않은 메일에는 작은 파란 점을 표시하고 부드럽게 점멸합니다. 메일을 열면 사라지며, 중복 동기화로 다시 켜지지 않습니다. 동작 줄이기를 켜면 점멸하지 않고 고정 표시합니다. 실제 동기화 오류는 계속 알립니다.
- OpenAI 기초·고급 분석 버튼을 메일 본문 아래에서 제거했습니다. 연결된 사용자가 ‘다시 요약’을 누를 때만 기기 내 요약과 OpenAI 재요약을 선택할 수 있습니다. 자동 요약은 계속 기기 내에서 처리하고 외부 전송 동의는 유지합니다.
- 할 일의 검색·필터 헤더와 새로고침 가능한 목록을 분리했습니다. 아래로 당겨 새로고침할 때 목록만 움직이고 상단 검색·필터는 고정됩니다.

## 개발 소스 — 녹음 상태·소스별 파형 (미출시)

- 휴대폰·태블릿 앱 상단에서 녹음 상태·경과 시간·실제 입력 파형을 잠시 펼쳐 표시한 뒤 약 3초 후 작은 캡슐로 줄입니다. 다른 탭에서도 유지되고, 탭하면 다시 펼쳐 확인할 수 있습니다.
- 입력이 두 개 이상이면 각각의 실측 파형을 별도 색으로 겹쳐 표시합니다. 무음·꺼진 소스·일시 정지는 가짜 움직임을 만들지 않으며 종료·취소 시 상태 표시를 없앱니다.
- iPhone의 다이내믹 아일랜드·잠금 화면과 iPad 잠금 화면에는 시스템 Live Activity를 추가했습니다. Mac은 위의 후속 개발 변경에 따라 시스템 메뉴 막대를 사용합니다. 시스템 표시의 갱신·확장·축소는 OS 정책을 따르며, 원음·전사·회의 제목·선택한 앱/창 이름을 표시 데이터로 전송하지 않습니다. 아래 제출 빌드에 반영됐다는 뜻은 아닙니다.
- 실시간 전사를 시작하지 못한 상태를 녹음 종료 때 다시 전체 녹음 실패로 보고하던 문제를 수정했습니다. 녹음 중에는 소스별 전사 경고를 일시 정지·종료 버튼 바로 아래에 표시하며, 저장된 원음·전사 실패 상태·재시도 안내를 보존합니다. 종료 단계에서 새로 발생한 오류는 계속 보고하고 전사 오류를 녹음 실패로 잘못 번역하지 않습니다.
- Apple 전사는 설치 상태뿐 아니라 실제 호환 입력 포맷도 확인합니다. 설치됨으로 보고되더라도 포맷을 제공하지 않는 런타임을 실행 가능한 모델로 잘못 선택하지 않습니다. 다운로드 가능한 Apple 언어의 기존 설치·준비 경로는 유지하며, 실시간 전사는 계속 Apple 기본 모델을 사용합니다. Whisper는 명시적으로 활성화한 녹음 종료 후 옵션에만 사용합니다.
- 녹음 언어 선택과 실시간 전사 실행 가능 여부를 분리했습니다. Apple 입력 포맷이 없는 환경에서도 지원 언어의 마이크 녹음·원음 저장은 Whisper를 켜지 않고 사용할 수 있으며, 전사 불가 경고와 저장된 전사 상태는 그대로 표시합니다.

## 개발 소스 — iPhone Duo 화면 대응 (미출시)

- 실제 iPhone Duo 시뮬레이터의 외부 화면에서 키보드를 열면 새 할 일의 큰 하단 저장 버튼이 마감 설정 영역을 가리던 문제를 보완했습니다. 세로 크기 분류만 보지 않고 편집기의 실제 높이에 따라 기존 상단 저장 동작을 사용합니다.

## 1.0.11 (10) — 심사 제출·공개 전

**2026-10-22 확인 기준**, iOS·universal Mac 빌드 **10**의 업로드·처리가 완료됐고 기존 빌드 9 요청을 취소한 뒤 재제출했습니다. **iOS 15:28 KST·Mac 15:32 KST 모두 Waiting for Review**입니다. 중국 본토 배포와 **2026-10-27 09:00 KST(00:00 UTC) 이후 자동 출시** 예약을 유지했습니다. 심사 승인·공개 출시는 아직 아닙니다. 아래는 빌드 9 이후 추가 변경이며, 할 일 관리가 앱의 중심이고 캘린더·회의·AI는 선택 기능입니다.

- iOS/iPadOS 할 일 배너를 화면 하단에서 카테고리 아래의 고정 영역으로 옮겼습니다. 소개 이미지는 내부 테스트 전용 광고 없는 모드로 촬영하며, 일반 사용자에게 광고 제거 설정이나 구매 기능을 제공한다는 뜻은 아닙니다. 아래의 제출 빌드 설명과 구분합니다.
- Mac 언어 검색을 선택 화면 상단의 전용 영역에 배치해 검색 위치를 분명하게 하고, 이전 화면으로 돌아가도 검색창이 남지 않도록 했습니다. 캘린더 사이드바 버튼을 상단 도구 모음으로 옮기고 이전·다음 달의 주가 중복 없이 이어지는 연속 스크롤로 바꿨습니다. 연결된 할 일 때문에 다일 일정 막대가 사라지던 중복 제거와 하루 일정 상단의 과도한 종일 여백도 수정했습니다.
- 할 일 보드의 드래그 미리보기를 제목만이 아닌 메타데이터를 포함한 전체 카드로 바꾸고 모델 설치·취소·삭제 컨트롤의 배치를 통일했습니다. 전체 대화 타임라인은 반복 소스 표시를 없애고 화자·시간·본문 중심으로 줄였습니다. 하루 일정 창은 빈 날·종일 일정·시간대별 일정을 나누고 시간 눈금과 일정 위치의 누적 오차를 수정했습니다.
- 같은 화자의 연속 전사문은 화자 이름을 반복하지 않고 본문·시간을 한 줄에 배치하며, 실제 화자가 바뀔 때만 간격을 둡니다. 큰 화면의 새 할 일 편집기는 넓은 입력 영역과 작은 상단 저장 버튼을 사용합니다. 하루 일정·새 할 일은 네이티브 팝오버의 바깥 클릭으로 닫히며, 저장 전 할 일 초안은 취소와 동일하게 버립니다. Gmail·Outlook 연결 펼침 행은 빈 공간까지 클릭할 수 있습니다.
- Mac 연속 캘린더에서 재사용되는 주 셀의 표시 뷰를 셀 수명 동안 유지하고, 스크롤·창 크기 변경 때 해당 셀의 실제 영역에 맞춰 배치하도록 보완했습니다. 주 전체가 선택·포커스되는 테두리를 없애고 날짜·일정 버튼의 동작은 유지합니다.
- GitHub CI의 출력 파이프가 `xcodebuild` 실패를 성공으로 가리던 경로를 제거하고, 최신 Xcode 러너에서 단위 테스트 결과 번들을 보존하도록 바꿨습니다. 이전 녹색 상태는 실제 빌드·테스트 통과의 근거로 사용하지 않습니다.

한국어·영어 iPhone/iPad의 실제 QA 화면 16장을 다시 촬영해 소개 이미지 20장·홈페이지 WebP 4장과 ZIP을 모두 교체했습니다. 소개 화면은 합성 예시 데이터와 내부 광고 없는 모드를 사용하며, 공개 광고 제거 기능이나 App Store 이미지 교체 완료를 뜻하지 않습니다. [PR 28](https://github.com/jung-geun/SIFT/pull/28)의 [main CI](https://github.com/jung-geun/SIFT/actions/runs/39651522003)·[Pages 배포](https://github.com/jung-geun/SIFT/actions/runs/39651522293)가 성공했고, 공개 이미지의 파일 해시 일치와 갤러리 동작을 확인했습니다.

## 1.0.11 (9) — 이전 심사 제출 기록

**2026-10-21 당시 확인 기준**으로 공개 앱은 **1.0.10**, 심사 제출 버전은 **1.0.11 (9)**였습니다. iOS/iPadOS는 스토어 문구·이미지를 보정해 **15:52 KST 재접수·Waiting for Review**, macOS는 **In Review**였습니다. 이 요청들은 10월 22일 빌드 10 재제출로 대체됐습니다. 아래는 빌드 9부터 포함된 기능과 사용 경로입니다.

### 화면과 안정성

- 재생 설정·파형·할 일 보드의 여백과 밝음/어두움 표시를 정리하고, 튜토리얼을 실제 입력란·설정 항목 옆에 배치했습니다. Mac 월간 캘린더는 출처 사이드바·미니 달력·월 격자를 정리하고 일정 조회 중 화면 이동 지연을 줄였습니다.
- Mac의 비활성 할 일·메일 도구 모음 충돌, 모델 미사용 상태의 불필요한 Metal 초기화, 짧은 회의 FLAC 저장·재생 수명 문제를 수정했습니다. 앱과 로컬 MLX의 컴파일 진단을 정리했습니다.
- iOS/iPadOS는 UMP가 허용할 때 하단 **320×50 배너 하나**를 사용합니다. 온보딩·튜토리얼·키보드·비활성 상태 등에서는 공간을 접고 전면·앱 시작·보상형 광고는 없습니다. Mac에는 광고 SDK를 연결하지 않습니다. [개정 개인정보처리방침](privacy-policy.html)은 **10월 27일 시행 예정**입니다.
- **등록 대기 항목은 일괄 AI 정렬·알림·자동 캘린더 등록에서 제외**하며 자동 등록에는 별도 동의가 필요합니다. iCloud 실계정 다기기 전파, 모든 언어의 AI 정확도, 실제 다중 소스 통화·물리 기기 성능까지 보증하는 변경은 아닙니다.

현재 소개 페이지의 예시 화면은 **1.0.11 (10) 소스의 QA 앱과 합성 데이터**로 다시 촬영했습니다. App Store 이미지 업로드·심사 승인·공개 출시와 구분합니다. 실행 범위와 원본 근거는 [dev의 UI 검증 기록](https://github.com/jung-geun/SIFT/blob/dev/ios/UI_TEST_PLAN.md)에 남깁니다. iOS/iPadOS 26 이상·macOS 26 이상용 제출이며 Android 신규 배포를 뜻하지 않습니다.

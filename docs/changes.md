## 기록 방식

- 현재 repo에서 확인되는 릴리즈 태그는 `1.0.5` 하나입니다.
- `1.0.0`~`1.0.4`의 세부 변경 이력은 태그나 릴리즈 노트가 없어 추정하지 않습니다.
- 앞으로 배포되는 버전은 이 페이지에 버전별로 추가합니다.

## 1.0.5 이후

아직 앱 버전은 올리지 않았습니다. 1.0.5 배포 이후의 유지보수 변경입니다.

- **배포 파이프라인**: TestFlight 배포 workflow가 `v*` 태그뿐 아니라 `1.0.5` 같은 숫자 태그도 감지하도록 조정했습니다.
- **패키지 무결성**: Xcode Cloud 사전 빌드에서 확인하는 `Package.resolved` SHA-256 기준값을 현재 패키지 상태에 맞췄습니다.
- **Apple Foundation Models 가용성 안내**: 실제 Apple Intelligence/Siri AI 활성화 조건에 맞춰 AFM 경로를 중앙 가용성 판정으로 통일하고, 미지원 환경에서는 Qwen 또는 통계 기반 폴백을 안내하도록 설정 화면 문구를 정리했습니다.

## 1.0.5 — 현재 배포 기준선 (2026-06-30)

### 사용자 기능

- **메일 기반 할 일 추출**: Gmail OAuth 연동으로 최근 메일을 읽고 마감·요청성 항목을 TODO 후보로 추출합니다.
- **원본 메일 확인**: 메일 탭과 TODO 상세에서 로컬 메일 캐시, Gmail 앱, Mail.app, Gmail 웹 순서로 원본 메일을 열 수 있습니다.
- **온디바이스 우선 이메일 분석**: 이메일 본문은 기본적으로 기기 내 분석 경로에서 처리하고, Gemini 본문 분석은 사용자가 별도로 허용한 경우에만 사용합니다.
- **캘린더 연동**: 마감이 있는 TODO를 EventKit 캘린더에 등록하고, 시스템 캘린더 변경을 TODO 상태와 동기화합니다.
- **AI 우선순위 정렬**: Apple Foundation Models 조건부 경로, MLX Qwen, Gemini API 선택 경로, 휴리스틱 폴백을 사용해 TODO 우선순위를 계산합니다.
- **행동 패턴/페르소나 분석**: 완료 시간대, 태그별 처리 속도, 마감 준수율을 바탕으로 개인화된 정렬 정보를 만듭니다.
- **온보딩과 설정 화면 정리**: 최초 실행 튜토리얼, iCloud 동기화 선택, 이메일·캘린더·AI·메모리 등 설정 상세 화면을 분리했습니다.
- **iCloud 선택 동기화**: TODO·페르소나·Audit·메모리 분석은 선택적으로 CloudKit Private DB에 동기화하고, 이메일 본문 캐시는 로컬 전용 컨테이너에 둡니다.

### 배포 준비/내부 품질

- **Outlook 연동 기반 작업**: MSAL/Microsoft Graph 연동 코드는 추가되어 있지만, 현재 repo의 `MicrosoftClientID`가 비어 있어 기본 빌드에서는 Outlook UI가 숨겨집니다. 공개 기능으로 광고하지 않습니다.
- **Gemini 라우팅 안정화**: Gemini API 키와 모델 설정을 분리하고, 실패 시 라우팅 오류와 폴백 경로가 드러나도록 정리했습니다.
- **테스트 보강**: Gmail, Outlook, Gemini, AI 라우팅, 이메일 수집, 튜토리얼, 설정 저장소 회귀 테스트를 추가·갱신했습니다.
- **CI 무결성 검사**: Xcode Cloud 사전 빌드에서 `Package.resolved` 해시를 검증해 Swift Package 변경 누락을 빠르게 잡습니다.

## 이전 버전

`1.0.5` 이전 버전은 현재 repo에서 세분화된 태그나 릴리즈 노트가 확인되지 않습니다. 이전 작업은 `1.0.5` 기준선에 포함된 상태로 기록하고, 앞으로의 변경은 이 페이지에 버전별로 남깁니다.

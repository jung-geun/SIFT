          운영 및 연결 설정 안내
          
    이 주소는 공개 메뉴에 연결하지 않습니다. 주소를 숨기는 것만으로는 보호되지 않으며, 모든 관리 API 요청은 별도 운영 키 인증을 거칩니다.
    
          
    관리자는 Jekyll의 site.feedback_api_url에 실제 Worker의 원점 URL(경로·쿼리 없이)을 설정하고 사이트를 다시 배포해야 합니다. 운영 환경은 HTTPS만 허용하며, 로컬 개발 페이지에서만 HTTP 루프백 API를 허용합니다. Worker의 관리자 CORS 허용 목록에 이 페이지의 원점이 있어야 합니다.
    
          
    키는 Worker 비밀 설정에만 보관하세요. 사이트 설정이나 소스에 넣지 마세요. 연결 해제는 이 탭의 내용을 지우지만 이미 서버가 받은 저장·삭제를 취소하지는 않습니다.

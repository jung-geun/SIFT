# メールを接続する

SIFTのメール接続は**IMAP方式**です。実際に接続を確認した**Gmail**を基準にご案内します。Googleでアプリパスワードを作成してSIFTに入力すると、受信トレイを確認し、メールの依頼をタスクとして整理できます。

メール接続は任意です。接続しなくても基本のタスク管理は利用できます。

## 1. Googleアカウントの2段階認証を有効にする

1. 接続するGmailアドレスで[Googleアカウント](https://myaccount.google.com/)にログインします。
2. **セキュリティとログイン → Googleへのログイン方法 → 2段階認証プロセス**に移動します。
3. 画面の案内に従って2段階認証を有効にします。すでに利用している場合は、次の手順に進んでください。

アプリパスワードの作成には2段階認証が必要です。詳しい手順は、[Googleの2段階認証ガイド](https://support.google.com/accounts/answer/185839?hl=ko)をご覧ください。

## 2. SIFT用のアプリパスワードを作成する

1. 同じアカウントで[Googleのアプリパスワード管理](https://myaccount.google.com/apppasswords)を開きます。本人確認を求められた場合は完了してください。
2. `SIFT iPhone`のようにアプリとデバイスが分かる名前を入力し、**作成**を選びます。
3. 表示された**16桁のアプリパスワード**をコピーします。

**Googleの通常のログインパスワードとは異なります。** 通常のパスワード、2段階認証コード、再設定用のバックアップコードをSIFTに入力しないでください。ここではGoogleが別途作成したアプリパスワードのみを使用します。

アプリパスワードのメニューが表示されない場合は、下の[接続のトラブルシューティング](#troubleshooting)をご確認ください。接続のために2段階認証や高度な保護機能を無効にしないでください。

## 3. SIFTでGmailを接続する

1. SIFTの**設定 → メール連携**を開きます。
2. **Gmail IMAP接続**の項目を展開します。
3. **Gmailメールアドレス**に、アプリパスワードを作成したアカウントの完全なアドレスを入力します。
4. **Google App Password**にアプリパスワードを貼り付けます。
5. **バックグラウンドでの自動メール取得**は、必要なときだけ有効にしてください。無効のままでも接続できます。
6. **Gmail IMAP接続**ボタンを押します。デバイスで本人確認を求められた場合は完了してください。
7. 確認が終わると、**Gmailアカウント**の行に**接続済み**と表示されます。

サーバー設定は自動で適用されます。Gmailのサーバーは`imap.gmail.com`、ポートは`993`で、SSL/TLSで接続します。アプリでサーバーやポートを別途入力する必要はありません。個人用Gmailは[IMAPが常に有効](https://support.google.com/mail/answer/7126229?hl=ko)なため、ウェブの設定で別途有効にする必要もありません。

## 接続したメールを確認する

**メール**タブで受信トレイをご確認ください。すぐに新しいメールを取得するには、**設定 → メール連携**で接続済みの**Gmailアカウント**の行を長押しし、**今すぐメールを確認**を選びます。

- **バックグラウンドでの自動メール取得**は、初期状態では無効です。有効にすると、デバイスを一度ロック解除した後は、ロック中でも保存されたアプリパスワードを使用できます。案内されるセキュリティ上のリスクを確認してから選択してください。
- **メールの自動分析**は、本文全体の確認・対応が必要な項目からのみタスクを提案する別の設定です。項目がない場合は自動で提案せず、手動で入力して保存できます。
- 一覧と本文全体は、自動分析の設定とは別に、アプリがアクティブになったときと定期的にデバイスに保存します。バックグラウンド取得は許可したアカウントにのみ適用され、iOSが実行の機会を決定するため、固定の間隔は保証されません。
- Gmailの**毎日の自動分析時刻**を調整できます。許可したGmailアカウントのバックグラウンドAI分析は、その時刻以降に1日1回試行します。Outlookの同じ日次分析は保証しません。分析対象期間の設定は、現在のIMAP一覧・本文の収集範囲を制限しません。

**既読への変更とゴミ箱への移動は、元のGmailにも反映されます。** 一覧を取得するだけでは既読にならず、未読メールの本文を確認した後に既読への変更を要求します。既読への変更に失敗しても、受信済みの本文は閲覧できます。ゴミ箱へ移動する場合も元のメールに影響します。

## 接続を解除する場合やデバイスを変更する場合

アプリパスワードは**このデバイスのKeychain**に保存します。iCloudへの全体保存に明示的に同意し、同じAppleアカウントとiCloudキーチェーンを使用する場合は接続情報を復元できますが、デバイスごとのアクセス承認とバックグラウンド許可は移行しません。新しいデバイスでは接続情報を確認し、必要なアクセスを自分で承認するか、そのデバイス用のアプリパスワードを作成して接続してください。

1. **設定 → メール連携**で接続済みアカウントの行を長押しするか左にスワイプし、**接続解除**を選びます。
2. SIFTから、このデバイスのアプリパスワードと接続アカウント情報が削除されます。
3. [Googleのアプリパスワード管理](https://myaccount.google.com/apppasswords)でも、使わなくなったSIFT用パスワードを**削除**してください。

**SIFTでの接続解除と、Googleでのアプリパスワードの取り消しは別です。** デバイスを紛失した場合は、先にGoogleで削除してください。接続解除によって、元のメールや保存済みのメール・タスクが一括削除されることはありません。

<h2 id="troubleshooting">接続がうまくいかないとき</h2>

- **アプリパスワードのメニューがありません。** 正しいアカウントか、2段階認証が有効かを確認してください。職場・学校のアカウント、セキュリティキーのみを使用する2段階認証、高度な保護機能プログラムでは、メニューがない場合があります。組織のアカウントでは、アプリパスワードとIMAPを使用できるか管理者にお問い合わせください。[Google公式ガイド](https://support.google.com/accounts/answer/185833?hl=ko)
- **パスワードが拒否されます。** 通常のパスワードではなくアプリパスワードであること、発行したアカウントと入力したアドレスが同じであることを確認してください。Googleの通常のパスワードを変更すると既存のアプリパスワードも取り消されるため、作成し直す必要があります。
- **保存済みのアカウントが未接続と表示されます。** ネットワークやデバイスでの本人確認の問題を解決してから、**再接続**を押してください。パスワードが取り消されている場合は、**App Passwordの変更**を選び、新しいアプリパスワードを入力します。
- **タイムアウトや安全な接続に関するエラーが発生します。** インターネット接続を確認し、別のネットワークで試してください。組織のネットワークであれば、IMAPポート`993`がブロックされていないかも確認してください。
- **接続できたのにメールがありません。** Gmailのウェブ画面で同じアカウントの受信トレイを確認し、SIFTで手動で新しいメールを取得してください。受信トレイが空でも、正常に接続することは可能です。

サポートが必要な場合は、エラーメッセージと発生状況のみをお知らせください。**通常のパスワード・アプリパスワード・認証コード・バックアップコードは、お問い合わせやフィードバックに送らないでください。** 画面を共有する場合は、メールアドレスとメールの内容も隠してください。

<h2 id="outlook">Outlookとその他のメールプロバイダー</h2>

SIFTの設定には**Outlook IMAP接続**の項目もありますが、現在のアプリパスワード方式はMicrosoftが要求する認証方式に適合しないため、接続成功を保証できません。Gmailの手順をそのままOutlookに適用しないでください。

- **Outlook.comの個人アカウント**は、Modern Authenticationを必要とします。[Microsoftの認証ガイド](https://support.microsoft.com/en-us/office/modern-authentication-methods-now-needed-to-continue-syncing-outlook-email-in-non-microsoft-email-apps-c5d65390-9676-4763-b41f-d7986499a90d)
- **Microsoft 365の職場・学校アカウント**のExchange Onlineは、IMAPの基本認証をブロックしており、アプリパスワードでも回避できません。[Microsoftの認証ポリシー](https://learn.microsoft.com/en-us/exchange/clients-and-mobile-in-exchange-online/deprecation-of-basic-authentication-exchange-online)

この制限はIMAP自体ではなく、プロバイダーの認証ポリシーによるものです。通常のMicrosoftアカウントのパスワードを代わりに入力したり、セキュリティを下げたりしないでください。現在のSIFTには、ほかのプロバイダーのサーバーを直接入力する汎用の接続画面はありません。

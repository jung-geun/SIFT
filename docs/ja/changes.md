# 変更履歴

<a id="version-1-0-15"></a>
## 1.0.15

### To-Do・メール一覧

- MacのTo-Do・メール一覧の常時表示の矢印をなくしました。行にマウスを重ねると右端にその他メニューが表示されます。行のクリックで詳細を開き、その他や右クリックでは操作メニューだけを開きます。
- iPhone・iPadのTo-Do詳細にある完了・削除を、大きな塗りつぶしボタンから標準のフォーム行に変更しました。削除は標準の削除色で区別し、タグ追加も簡潔にしました。

### カレンダー

- iPhone・iPadのカレンダーの左上に年と月を一緒に表示し、スクロールした月に合わせて更新します。年末・年始でも、その年と月を確認できます。
- カレンダー内の月の見出しにも年を表示し、異なる年の同じ月を区別できるように改善しました。

- iPhoneや幅の狭いiPadの週表示では、一度に2〜3日を表示します。幅の広いiPadでは7日をまとめて表示できます。
- 日付を自然な慣性で横スクロールできるようにしました。日付を右へスワイプしても前の画面には戻らず、戻るボタンは引き続き使えます。
- 終日・1日以上続く予定を日ごとに繰り返さず、期間をつなぐ1本のバーで表示します。日付見出し・時間列・バーは一緒にスクロールし、時刻の目盛りは固定します。1日未満の時刻指定予定は、日付をまたいでも各日の時間表に表示します。

### メール

- 本文全体の分析の**確認・対応が必要**な項目からのみタスクを提案します。項目がない場合はメールの件名・要約をタスクに変換せず、手動で入力したタスクを別途保存できます。
- 1通のメールにある複数の対応項目をそれぞれ保存し、タイトルを編集した後も同じ項目の重複登録を防ぎます。手動で追加したカレンダーの予定もタスクごとに区別し、元のメールへの参照を保持します。
- 切断されたIMAP接続を次の取得時に再接続し、既読への変更の失敗によって本文の受信まで妨げられないように改善しました。別のアカウントの接続で既読・ゴミ箱への操作を実行しません。
- アプリがアクティブになったときと定期的に、一覧・本文全体をデバイスに保存します。AI分析をオフにしてもキャッシュを保持し、バックグラウンド取得は許可したアカウントにのみ適用され、実行時刻はiOSが決定します。
- メールの要約カードの上下の余白をそろえ、対応項目の選択画面で長い項目名を読めるように改善しました。
- 大きな添付ファイルを除いて本文全体と表示用HTMLを取得し、末尾の対応項目を保持します。端末の接続失敗で同期済みの有効な要約を消さず、削除の実行取り消し後もメール対応項目の出典と重複防止を維持します。

### 設定・同期

- **同期の競合**画面で、項目ごとのバージョンと異なる内容を比較し、使用するバージョンを自分で選択して適用できます。比較中に変更された項目は再確認を求め、競合のないほかの項目の同期は継続します。
- 競合を解決する前に元のバージョンをデバイスに保管し、**保管したバージョン**から再び比較・復元できます。自分で選択したバージョンを使って、同じ項目の重複を1つにまとめます。
- 広告のプライバシーフォームのアプリ構成エラー、ネットワークエラー・タイムアウト、フォーム提供の失敗を区別し、解決方法を案内します。Google側の設定の問題を、単なる再試行で解決できるエラーとして表示しません。
- 旧バージョンのタスクのiCloud復元互換性を改善しました。新しいメール対応項目のタスクは1.0.14では読めず同期が停止する場合があるため、同じiCloudアカウントのiPhone・iPad・Macをすべて今回のバージョンに更新してください。

<a id="version-1-0-14-13"></a>
## 1.0.14 (13)

### 会議

- 要約でタスクに分類された文の横に、**タスクを追加**ボタンを表示します。別の候補一覧やタスク名の再要約を挟まず、確認した文をそのまま登録待ちに追加し、原文の根拠確認と重複防止を維持します。
- **再要約**で、Apple Intelligence、GPT-6.1 Sol、GPT-6 Lunaを直接選択できます。GPTは接続済みのアカウントとデバイスごとの会議送信の同意がある場合に限り使用し、エラー・キャンセル時は以前の結果を保持します。
- カスタムの要約指示が空でも、形式の選択と指示の編集ができるように修正しました。
- Apple Intelligenceによる長い会議の処理を段階に分け、出力言語の指定と原文の根拠検証を改善しました。
- 同じ話者の連続した文字起こしと、前後の話者が同じ未検出区間を段落としてまとめて表示します。手動の区切り・ソースの変更・実際に重なった発話は保持し、元の話者の割り当ては変更しません。
- 要約の複数の根拠ボタンを、位置へのリンクと根拠メニューに整理しました。
- 確認後に、**会議全体と所属する音声ソース・文字起こし・要約・元の音声**を削除できます。登録済みのタスクと外部に保存したファイルは保持します。
- 個別ソースの原本ZIP/WAV、または全ソースの原本ZIPを、iPhone・iPadの「ファイル」とMacの保存画面から保存できます。複数ソースのファイルと開始オフセットを区別して保持します。
- Macの音声取り込みに、Finderからのファイルのドラッグ＆ドロップと貼り付けボタン・⌘Vを追加しました。元のファイルは変更しません。
- 会議の復旧時に、子・メンバーシップの変更を保存してから復旧記録を整理するように修正しました。保存に失敗した場合は、既存の文字起こし・元の音声・復旧記録を保持します。
- 要約の出力設定だけを変更した場合は、既存の要約を保持します。原文の根拠が変わっていないことを確認できる要約では、タスク登録も維持し、実際の根拠が変わった場合や検証できない場合は登録をブロックします。
- Macの会議アクティビティ検出とアプリ別の出力収集を改善しました。選択したアプリの実行ファイル・プロセスの所有関係を確認し、収集対象が変わった場合は停止して再選択を求めます。共有WebKit helperを使用するSafariのアプリ別収集には対応しません。

### 設定・アカウント・同期

- AIアカウント画面から確認できないプランの等級と不要なモデル一覧を削除し、接続状態・接続テスト・送信同意・使用量を中心に整理しました。
- ChatGPTのJSONリクエスト形式と完了応答の処理を修正しました。このデバイスで確認したアカウント別の入力・出力・キャッシュ済み入力トークンと応答数を表示し、アカウント全体の使用量や残りの上限として解釈しないようにしています。
- 変更のないアカウント接続記録が、全体同期を繰り返し予約していた問題を修正しました。
- iCloudの削除記録の互換性と復旧を改善しました。内容が異なる重複識別子は勝手に上書きせず、その項目だけを保留にして、ほかの変更の同期を続けます。
- 会議・AI・ベータ機能の設定の重複した説明や空の項目を減らし、小さい画面・大きい文字でもモデル行と選択値が切れないように改善しました。
- iPadのペルソナのリセット・生成ボタンのタッチ領域を広げました。
- iPhone・iPadの設定に、**広告の同意とプライバシー**への入口を追加しました。Googleの同意状態を再確認し、フォームのエラーを同意完了として扱いません。Macで広告を除外する方針は維持します。

<a id="version-1-0-13-12"></a>
## 1.0.13 (12)

- 自動同期での保護された接続情報の確認は認証画面なしで行い、別途の承認操作で認証の目的・現在のグループ・キャンセル・待機状態を案内します。
- 小さな同期の変更をサイズを制限した単位でまとめて保存し、ディスクへの書き込みとCloudKitへの書き出しリクエストを減らしました。原文・リビジョンID・途中の失敗後の再開とキャンセル処理は保持します。
- 会議のシステム音声エラーの失敗段階・SDKコードを保持し、Macのキャプチャ権限を案内します。診断の収集を後から許可した場合も、エラーを失いません。
- エラー報告の作成キャンセル・送信失敗後も、診断の確認内容・下書き・送信IDを保持し、実際に診断の受付が成功したときだけ送信完了として扱います。

<a id="version-1-0-12-11"></a>
## 1.0.12 (11)

- モバイルのカレンダーの月表示の密度・年・日・複数日表示、連続スクロール・ピンチ・今日への移動と、幅の狭いiPad画面を改善しました。
- Macのカレンダーで、空き時間のクリック・ドラッグによる予定の作成、予定の端のドラッグによる時刻調整、右クリックによる編集・削除ができます。
- 予定を直接編集・削除する際、既存のタスクの関連付け・完了記録・繰り返しの予定・タイムゾーンの境界を保持し、削除した予定が自動登録で再び作られないように対処しました。
- 実際の入力波形、iPhone・iPadのLive ActivityとMacのメニューバーの録音表示を追加しました。リアルタイムの文字起こしにはAppleの標準モデルを使用し、任意のWhisperは終了後の処理にのみ使用します。
- 録音中の文字起こしの失敗と元の音声の保存失敗を区別し、Appleの文字起こしが実際の入力フォーマットに対応しているかを確認するよう改善しました。
- Macの音声取り込みに、ユーザーが選択したファイルの読み取り権限とネイティブの開くパネルを適用しました。原本を変更せず、ローカルに保存・再生します。
- 設定をAI・会議・タスク・ルーティンの役割に合わせて整理しました。Apple Intelligenceの実際の準備状態と代替ローカルモデルの使用同意を区別し、外部分析は接続・対応地域・個別の共有同意がある場合に限り実行します。
- メール同期の成功ポップアップを削除し、まだ開いていない新しいメールに青い点を表示します。
- タスクの検索・フィルターを固定し、空き領域のダブルクリック・ダブルタップでタスクを作成できるようにしました。
- Duoの画面切り替え時に新しいタスクの下書きを保持し、小さい画面で保存ボタンが入力領域を覆わないように改善しました。
- Macのタスクボタン・編集・明暗のコントラストと、カレンダーの予定照会・スクロールを改善しました。

<a id="version-1-0-11-10"></a>
## 1.0.11 (10)

- iPhone・iPadのタスクのバナーを、画面下部からカテゴリー下の固定領域に移しました。
- Macの言語検索を選択画面の上部に配置し、前の画面に戻ったときに検索欄が残らないように修正しました。
- Macのカレンダーのサイドバーボタンを上部のツールバーに移し、前月・翌月の週が重複せずにつながるよう修正しました。
- 関連付けられたタスクのために予定が消えてしまう問題と、1日の予定の上部の過剰な余白を修正しました。
- タスクのドラッグプレビューにメタデータを含め、モデルのインストール・キャンセル・削除コントロールを統一しました。
- 会議の会話タイムラインを話者・時刻・本文を中心に整理し、同じ話者の繰り返しの見出しと余白を減らしました。
- 1日の予定の時間目盛りと配置のずれを修正し、大きい画面のタスクエディターとGmail・Outlookの接続行のクリック領域を改善しました。
- Macの連続カレンダーのスクロール・ウインドウサイズ変更への対応を改善し、不要な週の選択枠を削除しました。

<a id="version-1-0-11-9"></a>
## 1.0.11 (9)

- タスク設定で期限通知・優先度の並べ替え用AI・ルールを管理し、Macのボードでタイトル・メモを編集できるよう整理しました。
- タスクの分析に使用するカレンダーを直接選択できます。選択を解除すると、新しい取り込みと未承認の提案の更新だけを停止し、承認済みのタスクは保持します。
- AIアカウントの接続・送信同意と、ローカルモデルのインストール・キャンセル・削除を分離しました。画面を開いただけでモデルをダウンロードすることはありません。
- 任意のiCloud保存の範囲を、メール・会議・ルーティン・単語帳・設定に拡大しました。接続情報にはiCloudキーチェーンを使用し、健康情報・OSの権限・ダウンロードしたモデルは除外します。
- 会議全体の音声と会話タイムラインをソースの共通時刻に合わせて再生し、最後に選んだ音声・要約の言語を記憶します。
- ルーティンの提案の根拠と予定を確認・承認できるようにし、対応するiOSデバイスの健康・運動記録は、別途の権限と同意によって接続します。
- ログインなしでフィードバックと選択した診断を確認・送信できます。実際の受付番号を受け取った場合に限り、成功と案内します。
- 再生設定・波形・タスクボード・チュートリアルと、Macの月間カレンダーの表示を改善しました。
- Macの無効なツールバーによるクラッシュ、モデル未使用時の不要なMetal初期化、短い会議のFLAC保存・再生の問題を修正しました。
- 登録待ちの項目を、一括AI並べ替え・通知・自動カレンダー登録から除外します。
